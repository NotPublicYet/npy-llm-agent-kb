## Summary
<h2>What's changed</h2>
<ul>
<li>Added <code>permissions.blockWritesOutsideWorkingDirectories</code>: Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode</li>
<li>Added an optional <code>groups</code> list to Claude apps gateway upstreams: only developers in the listed IdP groups are sent to that upstream, on failover too</li>
<li>Added <code>guardrail_trace</code> to Claude apps gateway Bedrock upstreams, to log which Amazon Bedrock guardrail filter fired on a request, without the matched text</li>
<li>Added idle compaction to VS Code and Claude Desktop's Code tab: a 200K+ token conversation left idle is summarized, and the summary is used on your next message if the prompt cache has expired</li>
<li>Fixed sessions failing turn after turn with "Invalid effort level" when an organization's admin caps a model's effort: Claude Code now lowers the effort, retries, and says which level it uses</li>
<li>Fixed <code>claude -p</code> exiting with code 0 and no output when startup failed; it now prints the error and exits 1</li>
<li>Fixed Bedrock sessions with many images failing every turn and <code>/compact</code> with "400 Input is too long." instead of removing older images and compacting</li>
<li>Fixed Microsoft Foundry sessions failing when the resource has no deployment for the default Sonnet, Opus or Haiku model: Claude Code now falls back to an older model of that family</li>
<li>Fixed repeated refused requests behind a gateway that doesn't accept tool search's <code>tool_reference</code> blocks: the request is sent again once without tool search, and the session remembers</li>
<li>Fixed TLS connections failing with <code>UNABLE_TO_GET_ISSUER_CERT</code> when the system certificate store holds a renewed root certificate that is cross-signed with its predecessor</li>
<li>Fixed MCP servers that also work without sign-in showing "needs authentication" after their stored sign-in stopped working; they are now used signed out</li>
<li>Fixed <code>claude mcp logout</code> reporting success when the MCP sign-in was not removed, for example while the macOS keychain is locked over SSH</li>
<li>Fixed extra sign-in renewals when several sessions share an Anthropic profile login and the credentials lock is busy</li>
<li>Fixed <code>claude ultrareview</code> and <code>claude remote-control</code> asking the workspace trust question in a CI job that has a terminal; with <code>CI</code> set they now refuse an untrusted folder at once</li>
<li>Fixed an administrator's TLS trust settings in managed settings not being applied in Claude Desktop sessions</li>
<li>Fixed model switching being refused on machines with managed plugin settings when one of your own <code>--plugin-dir</code> or <code>--plugin-url</code> plugins had a broken manifest or failed to download</li>
<li>Fixed the Bedrock and Vertex model upgrade offer coming back at every start when managed settings pin the model</li>
<li>Fixed <code>forceRemoteSettingsRefresh</code> set only in remote managed settings no longer applying once the stored copy had expired, which let sessions start without policy when the server could not be reached</li>
<li>Fixed "Continue automatically at usage limit" continuing more than three times without a prompt from you when a task restarted itself between waits (a /goal check-in, a background or scheduled task)</li>
<li>Fixed background and cloud sessions started with Ultracode turning it back on at their next start after it had been switched off</li>
<li>Fixed the last broken reply and its retry prompts staying in the conversation after Claude gave up on a tool call that could not be parsed</li>
<li>Fixed a PreCompact hook with very large output making compaction fail or repeat; each hook's output is now cut at 10,000 characters</li>
<li>Fixed background diff refreshes briefly taking the repository's index lock, which could make a git command run at the same moment fail with "Unable to create '.git/index.lock': File exists"</li>
<li>Fixed markdown tables jumping between grid and stacked layouts on half-typed rows while streaming, and long tables falling back to raw pipes</li>
<li>Fixed the /resume picker showing the text of CLAUDE.md or CLAUDE.local.md as a session's title when the session only ran slash commands</li>
<li>Fixed <code>/btw</code> answering from the main conversation when asked from a subagent's open transcript</li>
<li>Fixed pasting an image over SSH to a Linux machine doing nothing silently; the prompt now says to copy the file over and paste its path</li>
<li>Fixed <code>claude remote-control</code> sessions that failed to start when the session service was slow for a moment: the worker's registration is now retried with growing waits</li>
<li>Fixed model switches over Remote Control that take over 8 seconds getting a "still pending" error instead of the final result</li>
<li>Fixed the <code>sandbox.excludedCommands</code> setting description saying listed commands always run outside the sandbox; it now says every command in a call must match an entry</li>
<li>Fixed shell and MCP calls that auto mode, a deny rule or a PreToolUse hook blocked, or that otherwise did not run, reading as if they ran in a collapsed tool group</li>
<li>Fixed sandbox protections not applying to a worktree entered by <code>claude -p --resume</code> or <code>--continue</code></li>
<li>Fixed hooks matching Bash not running on shell commands started by the Monitor tool; such hooks can block or ask, but not approve or rewrite those commands</li>
<li>Fixed a settings file excluded with <code>--setting-sources</code> still supplying some settings, such as auto mode rules and saved permission consents</li>
<li>Fixed auto mode reporting a call as blocked, and listing it in <code>/permissions</code>, when its safety check gave no verdict</li>
<li>Fixed a Claude apps gateway Vertex upstream hanging for minutes when a Google token endpoint accepts the connection and never answers</li>
<li>Fixed the Claude apps gateway's start-up warning for a deprecated Claude Desktop key that it still serves as written saying "stops being accepted" after the key's end date</li>
<li>Fixed <code>/upgrade</code> opening the browser and starting a new login for plans billed through the App Store or Google Play; it now says where to change the plan</li>
<li>Fixed <code>--resume</code>, and rewinding past a switch to another model after a refusal, moving a session on a model name Claude Code doesn't recognize to a different model</li>
<li>Fixed requests failing when a gateway or cloud provider refuses one of Claude Code's beta headers by name: the request is sent again without it</li>
<li>Fixed model IDs spelled with a dot behind an LLM gateway, such as <code>claude-opus-4.8</code>, being treated as an older model with the wrong context window, output limit, effort, thinking mode and cost</li>
<li>Fixed Remote Control clients showing a stray "Compacted (ctrl+o to see full summary)" row after /compact</li>
<li>Fixed the cloud sessions tip and the Remote Control idle notice showing when an organization's policy turns those features off</li>
<li>Fixed a resumed claude.ai cloud session making a model call nobody asked for when the previous worker stopped just after receiving a new chat's files</li>
<li>Fixed WebFetch in Cowork cloud sessions silently dropping a PDF's text past 100,000 characters; it now says how much was unread and where to read on</li>
<li>Fixed Claude being told only that a command was declined after you stopped it with Esc or Stop in a cloud session or the IDE; it now also hears that the command may have run</li>
<li>Fixed blank lines at the top of a code block disappearing when the code block opens a quote</li>
<li>Fixed a blank line appearing above some <code>⎿</code> rows in the transcript view (Ctrl+O)</li>
<li>Fixed vim mode <code>dw</code>, <code>dW</code>, <code>yw</code> and <code>yW</code> carrying on past the end of the line, and made <code>w</code> and <code>W</code> stop on empty lines</li>
<li>Fixed x and Enter in the agent panel sometimes acting on the wrong agent when another agent started or finished</li>

<li>Fixed pasted text being lost when a row in the prompt footer was selected</li>
<li>Fixed vim mode <code>p</code> over a character selection ignoring whether the yanked text was whole lines</li>
<li>Fixed vim mode <code>aw</code> and <code>iw</code> taking the line break at the end of a line</li>
<li>Fixed ↓ selecting footer items hidden by the ? help menu, the command list or a paste hint</li>
<li>Fixed Esc on a command's panel, such as <code>/btw</code>, also interrupting the subagent whose transcript is open</li>
<li>Fixed the welcome header in fullscreen mode showing the session's model while viewing a subagent or teammate that runs on a different model</li>
<li>Fixed the fullscreen transcript being left mid-conversation after "Restore conversation" in the rewind menu while scrolled up</li>
<li>Fixed a rare case where a deleted session could reappear in the resume list as an almost empty entry</li>
<li>Fixed prompts containing tags such as <code>&lt;bash-stdout&gt;</code> or <code>&lt;local-command-stdout&gt;</code> not being acknowledged to a local stream-json host</li>
<li>Fixed sessions staying untitled when the first prompt failed (for example on a usage limit) and the conversation continued afterward</li>
<li>Fixed the skill file watcher checking every removed skill kept in <code>~/.claude/skills/.trash</code>, which added file system load that grew with each removal</li>
<li>Fixed the session name from /rename disappearing while Claude asks for permission or a plan decision, so side-by-side sessions stay identifiable</li>
<li>Fixed background sessions that fail to start being reported as a deleted daemon binary when the binary is still on disk</li>

<li>Fixed <code>~/.claude/skills/.trash</code> and <code>~/.claude/plugins/.trash</code> growing without limit: each now holds about 1024 entries, whatever <code>cleanupPeriodDays</code> says</li>
