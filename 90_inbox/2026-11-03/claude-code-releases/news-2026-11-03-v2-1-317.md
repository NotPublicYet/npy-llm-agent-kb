## Summary
<h2>What's changed</h2>
<ul>
<li>Added a warning to <code>/schedule</code> when a new cloud scheduled task gets connectors you did not ask for, with how to remove them</li>
<li>Added a check that asks before a web or shell tool call sends your account email address to the network</li>
<li>Added <code>onFailure: "block"</code> for Agent SDK hook callbacks, so a callback that fails blocks the action instead of letting it run</li>
<li>Added a notice in Claude Desktop's Code tab when your organization's remote managed settings haven't loaded for the session, and another once they do</li>
<li>Added a notice when auto mode's check has no answer for a subagent's tool call, which used to leave nothing in the main view</li>
<li>Added <code>anthropic.plan</code>, <code>anthropic.seat_type</code>, <code>anthropic.provider</code> and <code>anthropic.custom_base_url</code> to OTel metrics, events and spans</li>
<li>Added a cost report to the Claude apps gateway admin API, <code>GET /v1/organizations/analytics/cost</code>, for reading past spend over a date range in total, per developer, per day or per IdP group</li>
<li>Added a daily record of each developer's IdP groups on Claude apps gateways with <code>admin:</code> set, kept for <code>admin.identity_retention_days</code>, which the cost report groups by</li>
<li>Added <code>CLAUDE_CODE_DISABLE_NESTED_SESSION_ID</code>: set it to <code>1</code> on a self-hosted runner to have <code>claude -p</code> run inside a session use that session's ID and transcript, as in earlier versions</li>
<li>Fixed project and local MCP servers disconnecting after the first turn in some Claude desktop sessions</li>
<li>Fixed auto mode failing every turn when an LLM gateway set as the base URL answers 403 or 422 to its server-side safety check (a 403 with an apiKeyHelper is unchanged)</li>
<li>Fixed <code>claude auth status</code> exiting before a slow token refresh was saved, which could sign you out on the next run</li>
<li>Fixed a project's <code>effortLevel</code> setting being ignored by sessions that an app starts ahead of time and then opens in the project, such as new sessions in the desktop app's Code tab</li>
<li>Fixed <code>claude --from-pr</code> reporting "No conversations found" in projects with many sessions when the linked session was older than the first page</li>
<li>Fixed the second of two simultaneous permission prompts showing no file path or command on claude.ai and the mobile apps</li>
<li>Fixed Remote Control and SDK hosts offering "don't ask again" on a mod's tool calls</li>
<li>Fixed session titles being lost in cloud and SDK sessions when a new message or Stop arrived while the title was generating</li>
<li>Fixed self-paced <code>/loop</code> wakeups sometimes not being scheduled when Claude left a field out of its request</li>
<li>Fixed auto mode in cloud sessions stopping for approval when the Artifact tool uploaded, wrote to a database or saved a file through the outputs folder</li>
<li>Fixed skills synced from claude.ai being lost or downloaded again every ten minutes when they can't be written to disk</li>
<li>Fixed <code>/schedule</code> leaving a cloud scheduled task's next run time and link out of its results after creating or updating it</li>
<li>Fixed screen readers speaking a running subagent's elapsed time and token count on every change in screen reader mode</li>
<li>Fixed a region or network block (HTTP 403) being shown as a sign-in failure; the error now explains the block</li>
<li>Fixed Claude saying a working claude.ai connector needed authorization or had failed in cloud sessions when a synced plugin included the same server</li>
<li>Fixed <code>claude -p</code> exiting 0 when a full disk or quota lost its transcript or ~/.claude.json writes; it now prints an error and, in text and json output, exits 1. Full NFS exports may be missed</li>
<li>Fixed edits to settings files made in the first second or so after launch not taking effect until a settings file changed again</li>
<li>Fixed old transcripts not being cleaned up on machines where some runs skip cleanup, such as runs using <code>--setting-sources</code></li>
<li>Fixed deleted agent team inboxes being re-created by a teammate's late message</li>
<li>Fixed a re-created agent teammate being removed from its team by an earlier shutdown approval</li>
<li>Fixed stored scheduled tasks being impossible to list or delete after scheduled tasks were turned off</li>
<li>Fixed Claude deleting your most recently updated <code>/team-onboarding</code> guide when asked to delete one without naming which</li>
<li>Fixed Claude saying a <code>/team-onboarding</code> guide was deleted when the server refused the delete</li>
<li>Fixed the Claude apps gateway hiding Amazon Bedrock's "Input is too long." error, which left sessions failing every turn with "upstream rejected the request" instead of compacting</li>
<li>Fixed self-hosted runner sessions losing recent turns or the whole conversation when restarted while a plan waited for approval</li>
<li>Fixed "Prompt is too long" after automatic compaction in sessions whose very large CLAUDE.md changed since it was last sent</li>
<li>Fixed high memory use and slow startup in headless sessions with many plugins that register commands</li>
<li>Fixed stdio MCP servers receiving an empty <code>AWS_BEARER_TOKEN_BEDROCK</code> when their env config sets it to empty; the variable is now unset, so the server can use the machine's own AWS credentials</li>
<li>Fixed API requests failing with "unable to get local issuer certificate" behind some TLS-inspecting proxies after a root certificate renewal</li>
<li>Fixed very long conversations losing their earlier summary when compaction had to shorten its own request</li>
<li>Fixed a PDF's own metadata being able to make Read and @-mentions under-count its pages</li>
<li>Fixed <code>DISABLE_PROMPT_CACHING_OPUS</code> and <code>DISABLE_PROMPT_CACHING_SONNET</code> having no effect on <code>[1m]</code>, other-region and undated spellings of the default model</li>
<li>Fixed <code>/artifacts</code> and the Artifact tool's shared list showing no shared artifacts when you have 200 or more of your own</li>
<li>Fixed Claude treating partial Grep and Glob results as complete when a search hit its time limit</li>
<li>Fixed OpenTelemetry exports to an <code>https://</code> endpoint through a proxy never being sent when they started while another export was still in progress</li>
<li>Fixed a flood of connection attempts to a proxy that blocks (HTTP 403) OpenTelemetry exports to an <code>http://</code> endpoint</li>
<li>Fixed OpenTelemetry exports hanging indefinitely behind a proxy that never answers; they now time out after 10 seconds, or <code>OTEL_EXPORTER_OTLP_TIMEOUT</code> up to 30 seconds</li>
<li>Fixed resumed sessions telling Claude again about a file change it already knew about</li>
<li>Fixed Claude sometimes not using a built-in tool in a resumed session after an earlier call failed because the tool was switched off</li>
<li>Fixed <code>/remote-control</code> answering "Unknown command" instead of saying that Remote Control is turned off by the <code>disableRemoteControl</code> setting</li>
<li>Fixed agent team teammates in tmux or iTerm2 panes starting in auto mode when the lead session was in manual mode</li>
<li>Fixed a background session sometimes losing a just-made change of permission mode when it was upgraded or retired</li>
<li>Fixed Ctrl+C stopping all running background agents when pressed to clear typed text at the prompt</li>
<li>Fixed /feedback showing "Enter to confirm" while a report is being sent</li>
<li>Fixed child processes of a stopped shell command sometimes being sent SIGTERM twice, which could make some programs skip their cleanup</li>
<li>Fixed <code>claude -p</code> run inside a cloud or self-hosted runner session sharing that session's ID: it wrote into the session's transcript, and a restart could resume the wrong conversation</li>
<li>Fixed <code>claude -p</code> run inside a cloud or self-hosted runner session generating a title of its own and sending it to that session</li>
<li>Improved the error shown on Microsoft Foundry when Azure credentials can't be loaded: it now says to check or refresh them, and reports as <code>cloud_credential_error</code></li>
<li>Improved <code>/design-sync</code> to say up front when your design system has moved to Claude, and stop before building instead of failing at upload</li>
<li>Improved the startup error when a required Claude apps gateway can't be reached: it points to the network instead of a sign-in, and says when the gateway's TLS certificate can't be verified</li>
<li>Improved the "Resume this session with" hint shown at exit to repeat the flags you launched with (for example <code>--chrome --debug</code>) ahead of <code>--resume</code></li>
<li>Improved how self-hosted runners recover from server errors: after a 5xx other than 501 or 529, a runner's next poll now opens a new connection instead of reusing the one that failed</li>
<li>Improved how self-hosted runner sessions recover from server errors: after a 5xx other than 501 or 529, a session now opens new connections instead of reusing the one that failed</li>
<li>Improved how self-hosted runner sessions recover when connections stop answering: after a heartbeat gets no answer, a session now opens new connections instead of trying each idle one in turn</li>
<li>Changed SendMessage so a message to a running background agent arrives earlier: its running command moves to the background, without being stopped</li>
<li>Changed subagents and teammates on a different model from the main conversation to use that model's saved effort level or its default, instead of the session's effort level</li>
<li>Changed exit to skip the "Background work is running" prompt for plugin monitors</li>
<li>Changed the built-in <code>plugin-authoring</code> skill to offer once, after a mod you built works, to help share the mod</li>
<li>Removed the Read tool's "file unchanged since your last Read" stub: reading an unchanged file again returns its content</li>
<li>Windows: Fixed every tool call being refused on some volumes where the native path lookup fails; the working-directory check now compares the folder's identity instead</li>
<li>Windows: Fixed the session scratchpad and other temporary paths growing with your project's path length in sessions not started by Claude Desktop, which made repositories cloned into them hit the 260-character path limit</li>
<li>Gateway: Fixed the status line and <code>/usage</code> showing a developer's own spend limit as 100% used after their group's pooled budget ran out</li>
<li>Self-hosted runner: Fixed Claude not seeing the interrupted tool call when a session moves to a new runner and the turn is older than <code>CLAUDE_CODE_RESUME_INTERRUPTED_TURN_MAX_AGE_MS</code></li>
<li>Self-hosted runner: Fixed an MCP server that was switched off coming back on after the session moved to a new machine, when the session service had refused to save the switch</li>
<li>Remote Control: Improved fork names when the app doesn't set one: a long name keeps its "(fork)" ending, and in sessions started with <code>claude remote-control</code> a fork of "Name (fork)" is "Name (fork 2)"</li>
<li>[VSCode] Fixed forked conversations dropping messages: only one of the tool calls Claude ran in parallel was kept, and the last messages a compaction kept were lost, which could leave Claude's answer without the question it answered</li>
<li>[VSCode] Fixed a message being lost when Claude did not finish starting in time: the extension now starts Claude once more before showing the error</li>
<li>[VSCode] Fixed the sign-in screen opening when a request is blocked for its region or network</li>
<li>[VSCode] Fixed the Account panel showing the plan name with a lower-cased second word</li>
<li>[VSCode] Fixed file links in a Claude tab opening on top of the chat instead of in another editor group</li>
<li>[VSCode] Fixed attachment chips, menus, banners and dialogs in the Claude panel staying small when <code>chat.fontSize</code> is raised</li>
<li>[VSCode] Fixed <code>ultrathink</code> not raising effort for its turn or showing its rainbow when telemetry is off</li>
<li>[Cloud sessions] Added a link card to cloud sessions, so you can open or decline a link an MCP server asks you to visit instead of the request going unseen</li>
<li>[Cloud sessions] Changed the organization environment dialog in admin settings to the personal dialogs' short layout: each section opens from a row, and unsaved input asks before closing</li>
<li>[Cloud sessions] Fixed adding a network secret for a host that already has one silently replacing it; the Add secret form now refuses and points you to the existing secret</li>
<li>[Cloud sessions] Fixed new scheduled tasks ignoring your organization's default environment: the form now starts on the one an admin chose instead of the Anthropic-hosted default</li>
<li>[Remote Control] Fixed the next message to an idle session going unanswered after you restart <code>claude remote-control</code>, when you sent it within a minute of your previous message</li>
<li>[Claude Tag] Changed newly pasted artifact links in Slack to show a simpler card with an Open button that opens the artifact in Claude, instead of Slack's side panel</li>
</ul>
