## Summary
<h2>What's changed</h2>
<ul>
<li>Fixed a deny or ask rule on a nested part of a compound shell command not holding over a user-installed mod's approval on managed machines</li>
<li>Fixed the terminal freezing on short code blocks with many unclosed <code>&lt;script&gt;</code> tags or deeply nested <code>${</code> substitutions</li>
<li>Fixed <code>Read</code> deny rules not applying to files @-mentioned, changed, or selected in the IDE through a symlink</li>
<li>[VSCode] Reverted a 2.1.288 change to <code>claude auth status</code> that may have made sign-outs more frequent</li>
<li>Improved how quickly large files open in a plugin code pane by laying the highlighted view out once at its final width</li>
<li>Fixed <code>plugin list</code>, <code>plugin eval</code> and <code>plugin update</code> showing a stale copy of a plugin installed from a local folder marketplace, and hot reload for a symlinked <code>--plugin-dir</code></li>
<li>Fixed installed mods not loading in the first session after an upgrade</li>
<li>Fixed a plugin's rows above the prompt showing a stale row while the Background tasks dialog was open in fullscreen</li>
<li>Fixed plugin panes drawing nothing when a link used a localhost address, an <code>@</code> in its path, an uppercase host or a <code>file:</code> path</li>
<li>Fixed a user-installed plugin being able to rewrite the descriptions of an organization-managed MCP server's sign-in tools</li>
<li>Fixed a freeze or forced quit at launch when a plugin drew a Box with a border style the terminal does not know</li>
<li>Fixed supervised and background sessions ending when a plugin's on-screen handler threw asynchronously</li>
<li>Fixed sessions ending with an interface error when a plugin region with no height kept growing</li>
<li>Fixed Bash deny and ask rules missing a command behind an environment variable prefix with an expanded value (e.g. <code>TZ="$HOME" rm -rf build</code>) when the sandbox auto-allows commands</li>
<li>Fixed a Bash deny or ask rule being skipped under sandbox auto-allow when a bare variable assignment came before the command</li>
<li>Fixed <code>claude plugin validate</code> skipping the plugin when the folder also holds a marketplace manifest</li>
<li>Added <code>agent.spawn</code> for teammates, one agent id across plugin hook events, and idle and waiting states in <code>$.agent.list()</code></li>
<li>Fixed sessions ending with "unrecoverable interface error" when a value a mod's <code>ui.render</code> hook wrote made a row throw while drawn; the engine now draws its own row instead</li>
<li>Fixed text with a tab, a stray escape and a C1 control, or a short text with a tab and CRLF line endings, drawing over the rows below it</li>
<li>Fixed right-aligned content in a mod's pane or band drawing under the close mark or <code>[-]</code>, which now also keep one column in from the terminal's edge</li>
<li>Fixed a mod's <code>Client</code> that fails while drawn taking down everything the mod drew around it; it now fails alone and raises <code>ui.fault</code></li>
<li>Fixed <code>claude plugin validate</code> failing an Anthropic marketplace's own plugin and listing a clean <code>plugin.json</code> in <code>--json</code></li>
<li>Fixed a mod's band that fails to draw briefly telling the cards under it to step aside</li>
<li>Fixed a failed plugin component showing <code>Error</code> or nothing as its reason when the failure carried no message</li>
<li>Improved the line a mod's author sees when its band or pane fails to draw: it names the mod and says nothing was drawn</li>
<li>Fixed published artifact pages freezing or crashing the reader's browser tab on short code blocks with many unclosed <code>&lt;script&gt;</code> tags</li>
<li>Fixed a mod's Client region staying failed for the whole session after the terminal threw while drawing it</li>
</ul>
