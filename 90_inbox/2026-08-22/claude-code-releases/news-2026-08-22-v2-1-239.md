## Summary
<h2>What's changed</h2>
<ul>
<li>Cost estimates (<code>/cost</code>, status line, <code>--max-budget-usd</code>) now include the 1.1× US-only-inference premium for data-residency workspaces</li>
<li>Added the one-time fullscreen renderer offer on Bedrock, Vertex, Foundry and other previously excluded setups; new installs there now start in fullscreen</li>
<li>Added <code>/claude-api upgrade</code> to migrate Python projects from <code>anthropic</code> 0.x to 1.x, and updated the skill's Python reference for 1.x (timeouts use <code>anthropic.Timeout</code>, not <code>httpx.Timeout</code>)</li>
<li>Cloud sessions: plugins synced from claude.ai now show as <code>name@synced</code>, work with <code>claude plugin enable/disable &lt;name&gt;@synced</code>, and never override a same-named plugin you installed</li>
<li>Alpine/musl builds: native image paste, clipboard, and audio-capture add-ons now load (musl-built binaries instead of glibc ones refused by the runtime)</li>
<li>The usage-limit message shown when your monthly spend limit is already used up now also says when your session or weekly limit resets</li>
<li>Fixed Bedrock streaming behind proxies that strip the response Content-Type header, which silently doubled billed API calls by re-running every turn non-streaming</li>
<li>Fixed Claude Code hanging at startup behind an HTTPS proxy when using Bedrock with an SSO profile and <code>awsAuthRefresh</code> — the credential pre-check now honors <code>HTTPS_PROXY</code></li>
<li>Fixed a raw crash dump when starting Claude Code from a directory that no longer exists; it now prints a clear message</li>
<li>Fixed Edit and Write calls pausing for about 5 seconds in JetBrains IDE terminals when the Claude Code plugin is connected</li>
<li>Fixed a race where pressing Esc with a prompt queued could let the next turn finish early, leaving the session idle while Claude was still working and letting a later resubmit repeat actions</li>
<li>Fixed WebFetch retaining expired page content in memory for the whole session instead of the intended 15 minutes</li>
<li>Fixed cloud sessions (Claude Code on the web, desktop and mobile apps) resuming out of plan mode after an idle worker restart</li>
<li>Fixed MCP elicitation forms taller than the terminal being clipped in fullscreen mode: the form now fits the window, with hidden fields reachable by scrolling and Accept/Decline always visible</li>
<li>Fixed remote MCP servers staying failed after a transient 5xx on a mid-session reconnect in cloud sessions or via SDK <code>setMcpServers()</code></li>
<li>Fixed custom session titles disappearing from <code>/resume</code> after more than ~64 KB of conversation was written following the rename</li>
<li>Fixed <code>claude -c</code>/resume picking up sessions from a different directory whose path differed only by characters like <code>_</code>, <code>-</code>, or <code>.</code></li>
<li>Fixed <code>/resume</code> and the agents view showing a session as recently changed (and reordering it) when only its file was touched or it was merely reopened</li>
<li>Fixed <code>/resume</code> in all-projects mode telling you to <code>cd</code> into a deleted directory (e.g. a removed worktree); such sessions now resume in the current directory</li>
<li>Fixed the <code>dark-ansi</code> theme rendering expanded tool results in fullscreen mode with text the same color as the background</li>
<li>Fixed the fullscreen renderer prompt reappearing on every launch when it could never be answered; it now stops after being shown on three launches</li>
<li>Fixed <code>.worktreeinclude</code> patterns starting with <code>**/</code> silently matching nothing when the target lived in a gitignored directory</li>
<li>Fixed agents, skills, and commands whose <code>.md</code> file starts with a UTF-8 BOM being silently ignored</li>
<li>Fixed <code>/insights</code> echoing literal <code>&lt;message&gt;</code> tags in its response on some models</li>
<li>Fixed marketplace <code>metadata.pluginRoot</code> having no effect: bare plugin source names now resolve under it as the docs describe</li>
<li>Fixed mouse movement in browser-based terminals inserting text like <code>"35;150;7M"</code> into the prompt when a mouse report arrived split across writes</li>
<li>Fixed custom theme overrides for the effort/ultracode status badge colors being ignored</li>
<li>Fixed OpenTelemetry trace fragmentation: tool executions deferred by a <code>PreToolUse</code> hook now resume in the original turn's trace instead of starting a new trace</li>
<li>Fixed vim mode in the agent view: Escape now switches to NORMAL mode and keeps your text instead of clearing the prompt</li>
<li>Fixed the <code>selection:copy</code> keybinding silently dropping a text selection that had been extended with Shift+Arrow keys</li>
<li>Fixed the <code>/voice</code> startup tip still appearing after voice dictation was enabled via the <code>voice.enabled</code> setting</li>
<li>Fixed shell-mode (<code>!</code>) Tab completion dropping the <code>./</code> from a <code>./script</code> path, which left a command the shell couldn't run</li>
<li>Fixed fullscreen mode answering a permission prompt or pressing a button when you clicked the terminal window only to bring it back into focus</li>
<li>Fixed slash-command panels (e.g. <code>/config</code>, <code>/model</code>) in fullscreen mode covering the latest messages; the conversation now stays pinned above the panel</li>
<li>Fixed the <code>/workflows</code> detail dialog overflowing the terminal and losing its header off-screen when opened while Claude is still responding</li>
<li>Fixed the Linux sandbox making a nonexistent <code>.git/config.worktree</code> unreadable, which broke every sandboxed git command in repos with <code>extensions.worktreeConfig</code> set</li>
<li>Fixed hooks failing with "posix_spawn ENOENT" after the session's working directory was deleted; they now run from the project root or home directory instead</li>
<li>Fixed <code>claudeMdExcludes</code> not excluding a symlinked <code>.claude/rules</code> file when the pattern names the rules directory or the symlink rather than its target</li>
<li>Fixed runaway session-title syncing to Remote Control when two Claude Code processes shared one background job's state (2.1.232 regression); title updates are now deduplicated and rate-limited</li>
<li>Fixed sessions whose title starts with <code>/</code> being unaddressable by <code>SendMessage</code> and shown as "(untitled)" in <code>ListAgents</code></li>
<li>Fixed Ctrl+W, Ctrl+U, Ctrl+K, Option+Backspace, Option+D and vim <code>df</code>/<code>dt</code> leaving a broken <code>[Pasted text #N]</code> placeholder when the cursor was inside it</li>
<li>Fixed masked (password-style) inputs such as the login code field letting their text be pasted back with Ctrl+Y elsewhere or saved to prompt history when cleared with double Esc</li>
<li>Fixed Ctrl+Backspace deleting one character instead of a word in search boxes</li>
<li>Fixed a request rejected by an organization policy check being re-sent before the rejection was shown</li>
<li>Improved the reminder shown after compaction so a skill's original arguments are not re-run as a new request</li>
<li>Long file paths on tool-use rows now truncate in the middle to stay on one line</li>
<li>Remote sessions keep sending keep-alives while a long <code>SessionStart</code> or <code>Setup</code> hook runs, so the container is not idle-reaped mid-hook</li>
<li><code>/goal</code>: repeat check-ins on long-running background work now back off (30 min, then 1 h, then every 2 h) instead of repeating every 30 minutes</li>
<li><code>/goal</code>: resuming a session from the <code>claude --resume</code> picker now restores its active goal</li>
<li><code>ListAgents</code> now tells a session its own name (the one peers use to message it), and <code>SendMessage</code> to your own name says so instead of "no agent named …"</li>
<li><code>ListAgents</code> and <code>/list-agents</code> now list your live teammates (previously only subagents and other sessions appeared, so a reachable teammate looked absent)</li>
<li><code>keybindingFlavor: "readline"</code> now also matches Bash for word keys: Alt+F and Ctrl/Option+→ stop at the end of the word, Alt+D deletes to it (Ctrl+Y pastes it back), and punctuation separates words</li>
<li>Persistent retry mode (<code>CLAUDE_CODE_RETRY_WATCHDOG</code>) now fails immediately on organization spend-limit and out-of-credits errors instead of waiting indefinitely for a reset</li>
<li>Claude in Chrome: <code>/clear</code> now closes the session's Chrome tab group, and empty groups are closed on <code>/resume</code> and when Claude Code exits</li>
<li>Remote sessions: images uploaded from mobile now include their saved file path, so Claude can copy them into files it creates</li>
<li>Claude Code on the web: requests from Bash and other tools to non-API anthropic.com hosts (e.g. www, docs) now go through the session's network proxy, so your environment's allowed domains apply</li>
<li>Remote Control: clearer message and <code>claude doctor</code> wording when Remote Control isn't enabled for your account</li>
<li>Windows: cross-session messaging is now available, so Claude Code sessions across your machines can message each other with <code>SendMessage</code> and find each other with <code>ListAgents</code>, as on macOS and Linux</li>
<li>[VSCode] "View usage" in the usage-limit banner now sits inline with the warning text instead of floating mid-banner</li>
</ul>
