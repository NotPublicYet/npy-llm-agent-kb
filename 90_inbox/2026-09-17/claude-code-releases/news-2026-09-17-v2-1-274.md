## Summary
<h2>What's changed</h2>
<ul>
<li>Added a visible warning when memory usage is critical, with steps to free memory or restart safely</li>
<li>Added <code>CLAUDE_CODE_MCP_STARTUP_WAIT_MS</code> to bound how long the first non-interactive turn waits for connecting MCP servers (<code>0</code> = don't wait)</li>
<li>Added <code>effort</code> attribute to the <code>claude_code.llm_request</code> OpenTelemetry trace span, matching the <code>api_request</code> event</li>
<li>Added <code>claude_code.managed_settings_resolved</code> OTel event: managed-settings sources and policy helper state; redacted settings and digests with <code>OTEL_LOG_MANAGED_SETTINGS=1</code></li>
<li>Added <code>store.connect_timeout_seconds</code> to the Claude apps gateway config to lengthen the Postgres connect timeout (default 5 seconds), and improved the boot error when the database is unreachable to point to <code>store.postgres_url</code> and the configured timeout</li>
<li>Added <code>enduser.sub</code>, the IdP subject, to the telemetry Claude Desktop and Cowork send through a Claude apps gateway</li>
<li>Added a Claude apps gateway warning when a replica has more requests open than the 256 it sends upstream at once, and a startup log line showing that limit</li>
<li>Added click-to-expand for collapsed teammate and agent messages in fullscreen mode</li>
<li>Fixed sessions getting stuck endlessly retrying "unexpected tool_use_id" 400 errors: corrupted transcripts now self-heal where possible, and otherwise a clear error (with a <code>/rewind</code> hint) ends the loop</li>
<li>Fixed MCP servers configured as <code>http</code> that only speak legacy HTTP+SSE failing to connect when they answer the first request with 422 or another 4xx error</li>
<li>Fixed Streamable HTTP MCP tool calls timing out after about 5 minutes even when a longer per-server <code>timeout</code> was set</li>
<li>Fixed MCP prompts and resources not refreshing when a server sends list-changed notifications without declaring <code>listChanged</code></li>
<li>Fixed MCP tool calls refused with 403 insufficient_scope being reported as an expired sign-in: the error now names the missing permissions and points to <code>/mcp</code> re-authentication</li>
<li>Fixed hook-driven sessions (such as an active <code>/goal</code>) ending with "Prompt is too long" instead of compacting when the context overflowed again after a reactive compaction</li>
<li>Fixed an active <code>/goal</code> being lost when resuming (<code>--continue</code> / <code>--resume</code>) a session that had compacted</li>
<li>Fixed <code>claude agents</code> losing <code>--model</code>, <code>--effort</code>, <code>--permission-mode</code>, <code>--allow-dangerously-skip-permissions</code> and <code>--agent</code> after an auto-update relaunch</li>
<li>Fixed a per-turn slowdown when a language server publishes project-wide diagnostics for thousands of files</li>
<li>Fixed subagents with <code>model: "opus"</code> on Bedrock, Vertex or Foundry leaving the session's model when its id has no recognizable model family (unless <code>ANTHROPIC_DEFAULT_OPUS_MODEL</code> is set)</li>
<li>Fixed self-hosted runner sessions failing every turn with a 401 after a few failed token refreshes, until the next scheduled refresh; the runner now keeps retrying, and fetches a new token after a 401</li>
<li>Fixed clickable links to local file paths doing nothing in VS Code and other terminals that require a <code>file://</code> URI</li>
<li>Fixed the transcript renumbering ordered lists in your own messages (typing "3. 2. 1." displayed "3. 4. 5."); numbers and "N)" markers now show as typed</li>
<li>Fixed AskUserQuestion preview notes being attached to a previously chosen option instead of the highlighted one</li>
<li>Fixed AskUserQuestion preview mode dropping the highlighted option when submitting a note with Enter</li>
<li>Fixed a resumed background agent keeping half of an interrupted tool batch when one of its calls was approved with a message</li>
<li>Fixed a local <code>claude -p --resume</code> started with <code>CLAUDE_CODE_RESUME_INTERRUPTED_TURN</code> not reporting background tasks the previous process left unfinished</li>
<li>Fixed the first turn of a cloud session sometimes starting without the tools of an SDK-hosted MCP server that was still connecting</li>
<li>Fixed background agent notifications claiming the agent had no live background work when it was still waiting on its own background task and would resume</li>
<li>Fixed error hints in Claude Desktop sessions to suggest slash commands like <code>/usage-credits</code> instead of CLI flags that cannot be used there</li>
<li>Fixed <code>/schedule</code> saving a routine's prompt without its message role when Claude writes the routine in the shape that listing routines returns</li>
<li>Fixed <code>/status</code> not showing the <code>apiKeyHelper</code> failure that its own error banner told you to check</li>
<li>Fixed <code>/fast on</code> in non-interactive sessions reporting on and then turning off under an organization's managed fast mode policy; it now says the organization has disabled it</li>
<li>Fixed the Artifact tool asking you to approve an update to an artifact that it then refused because the session had not read the latest version</li>
<li>Fixed Cowork and claude.ai cloud sessions with network access on treating reads of a teammate's artifact as if network access were off</li>
<li>Fixed a plugin or marketplace directory with no git repository of its own taking its version from an enclosing git repository, such as a git-managed <code>~/.claude</code></li>
<li>Fixed <code>--strict-mcp-config</code> with an empty <code>--mcp-config</code> holding the first non-interactive turn for up to <code>MCP_TIMEOUT</code> on incidental MCP servers</li>
<li>Fixed Stop prompt hooks re-sending their whole prompt on every block in a conversation; repeat blocks now name the condition with a 500-character label</li>
<li>Fixed extra empty editor windows opening at startup on Linux under Wayland when running inside the Cursor or VS Code terminal</li>
<li>Fixed an unhandled promise rejection in the Claude apps gateway when Postgres drops a connection during a spend check</li>
<li>Fixed Claude apps gateway cutting every open stream on SIGTERM: it now lets in-flight requests finish for up to 25 seconds before exiting (<code>CLAUDE_GATEWAY_DRAIN_TIMEOUT_MS</code>)</li>
<li>Fixed <code>installed_plugins.json</code> being rewritten on nearly every start-up when plugin policy comes from remote managed settings, which made Claude Desktop reload every open session's plugins</li>
<li>Fixed headless and SDK sessions making a separate model call for every background task that finished; completions already queued are now answered by one call</li>
<li>Fixed the Bash tool re-sourcing the shell profile (a multi-second stall on the next command) after every plugin reload; it now does so only when the plugins' <code>bin/</code> directories changed</li>
<li>Fixed plugins with a top-level <code>$schema</code> in <code>hooks/hooks.json</code> showing an "unknown key" notice</li>
<li>Fixed MCP connection errors and the MCP login tool's description showing secrets resolved from <code>${VAR}</code> placeholders in MCP configs</li>
<li>Fixed Bash permission checks for commands that loop over or assign certain special shell variables; these commands now ask for permission</li>
<li>Fixed worktree-isolated sessions accepting Bash commands with certain nested shell expansions; these are now refused</li>
<li>Fixed the Edit permission prompt preview sometimes showing a different location than the approved edit in files with multi-byte characters</li>
<li>Fixed background commands being stopped after 30 idle minutes on machines under mild memory pressure; they're now stopped only when memory is critically low, and the debug log says why</li>
<li>Fixed a message a subagent sends to the main session disappearing from the Claude Desktop transcript after a relaunch</li>
<li>Fixed a plugin loaded from a <code>.zip</code> being served from a stale extraction after several overlapping reloads</li>
<li>Fixed a sub-agent's progress summary being replaced by a runaway multi-paragraph reply</li>
<li>Improved startup in <code>--input-format stream-json</code> sessions: the first turn no longer waits up to 2s for still-connecting MCP servers whose tools tool search defers; they arrive on a later turn</li>
<li>Improved Monitor tool notifications: a script's final output and its exit now arrive as one notification instead of two, saving a model turn</li>
<li>Improved Artifact tool errors: when you are not signed in to claude.ai the terminal now says so on the first attempt, and Claude is told to stop retrying a rejected call sooner</li>
<li>Improved artifact publishing: a publish built on an older version is stopped before it is sent, with the newer page to merge</li>
<li>Improved safety checks before removing an agent worktree that contains submodule checkouts</li>
<li>Improved <code>OTEL_LOG_RAW_API_BODIES=file:&lt;dir&gt;</code> output: a new <code>index.jsonl</code> and <code>request_body_id</code> / <code>message.id</code> event attributes link each response to its request file and transcript message</li>
<li>Improved Claude apps gateway boot: it now tries the first Postgres connection up to three times before exiting, so a database that is reachable a few seconds late no longer fails the boot</li>
<li>Improved the Claude apps gateway's spend-limit check under load: it now takes one database round trip instead of four, so fewer checks time out on a busy gateway</li>
<li>Improved Claude apps gateway sign-in rate limit errors: <code>/login</code> now explains the refusal, and the gateway log says which limit was hit and which setting to change</li>
<li>Changed Bedrock, Vertex, Foundry and telemetry-disabled installs to use the v2 MCP client and MCP 2026-07-28 negotiation with direct HTTP servers by default, as other installs already do (opt out: <code>MCP_SDK_GENERATION=v1</code> or <code>MCP_PROTOCOL_NEGOTIATION=legacy</code>)</li>
<li>Changed <code>/code-review</code> to use leaner inline review prompts for every model that has no tuned settings of its own, instead of spawning many review subagents</li>
<li>Changed <code>"type": "sdk"</code> MCP entries in <code>.mcp.json</code>, settings, plugins and agent files to be skipped with a warning: only an SDK host application can register in-process servers</li>
<li>Changed artifact watching in local sessions: a new version published elsewhere no longer starts a turn; Claude learns of it from a later Artifact tool result</li>
<li>Changed plugin and marketplace clones to leave Git LFS files as pointers instead of downloading them; <code>git lfs pull</code> in the checkout fetches them</li>
<li>Changed self-hosted runners to skip a read-only repository the git host refuses at the access check instead of failing the session start</li>
<li>Changed the <code>/status</code> GitHub line to read "Cloud sessions", and <code>/web-setup</code>, <code>/ultrareview</code>, and teleport messages to say "cloud session" instead of "Claude Code on the web"</li>
