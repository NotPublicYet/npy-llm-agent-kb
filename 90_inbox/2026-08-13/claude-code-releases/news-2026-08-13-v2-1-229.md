## Summary
<h2>What's changed</h2>
<ul>
<li>Documented <code>claude remote-control --continue</code> for resuming the most recent Remote Control session</li>
<li>Added server-supplied Claude Code hook support for self-hosted runner sessions, matching managed-environment behavior</li>
<li>Added SSE keepalive pings to gateway streaming responses during long thinking pauses, preventing idle-timeout disconnects on Vertex and Bedrock upstreams</li>
<li>Added plugin marketplace <code>command</code> sources: a local command (e.g. an IDE) prints the plugin directory, which is re-resolved each session and applied without a restart; <code>mode: "link"</code> uses it in place</li>
<li><code>ListAgents</code> now marks disconnected Remote Control sessions as <code>offline</code> and labels your cloud sessions as <code>cloud</code></li>
<li>Fixed long responses partly disappearing while streaming and being printed twice in the terminal</li>
<li>Fixed a crash to the error screen (including on <code>--resume</code> of the affected session) when a tool call had a non-string <code>glob</code>, <code>file_path</code>, or <code>command</code> value</li>
<li>Fixed a RangeError crash when a progress bar or markdown table rendered in a very narrow terminal window (could also crash <code>claude --continue</code>/<code>--resume</code> at startup)</li>
<li>Fixed a crash on Windows when a tool call or message referenced a file by an extended-length (<code>\\?\</code>) or UNC path</li>
<li>Fixed auto mode failing on every tool call for users who disable the attribution header via <code>CLAUDE_CODE_ATTRIBUTION_HEADER</code> (direct Anthropic API connections)</li>
<li>Fixed <code>/model</code> rejecting Sonnet/Opus 1M for claude.ai subscribers using a custom <code>ANTHROPIC_BASE_URL</code> gateway</li>
<li>Fixed MCP OAuth with strict authorization servers by using <code>127.0.0.1</code> instead of <code>localhost</code> in the redirect URI</li>
<li>Fixed Remote Control clients showing a stuck working spinner after a slash command typed in the laptop terminal</li>
<li>Fixed the Claude Code Review workflow generated by <code>/install-github-app</code> completing without posting its review on the pull request</li>
<li>Fixed multi-second UI stalls after editing a file with thousands of IDE diagnostics while the IDE extension is connected</li>
<li>Fixed one-shot <code>claude plugin</code> commands leaving a stray liveness file that could prevent cleanup of outdated plugin versions</li>
<li>Fixed dynamic workflows inside CPU-limited containers using the host machine's core count instead of the container's CPU limit</li>
<li>Fixed a file-watcher handle leak after atomic file replacements, and an uncaught error on Windows when the scheduled-tasks watcher failed on a network or virtual filesystem</li>
<li>Fixed SDK and <code>--input-format stream-json</code> sessions getting a 400 API error when a whitespace-only message was submitted</li>
<li>Fixed conversations whose messages alone exceed the API's 32 MB request limit retrying compaction when no images or documents can be stripped; they now fail once with a clear message</li>
<li>Fixed OpenTelemetry export from Claude Desktop sessions being rejected by the Desktop-managed gateway when that gateway is also the telemetry endpoint</li>
<li>Fixed self-hosted runner and other remote sessions exiting at startup when <code>managed-mcp.json</code> is deployed and the server delivers MCP servers; those servers are now skipped with a warning</li>
<li>Fixed self-hosted runner repository preparation hanging on a Git Credential Manager prompt; git now fails fast when credentials are missing</li>
<li>Improved workflow fan-outs to stagger same-prefix sibling agents so subsequent agents read the cached prompt prefix instead of re-paying it (<code>CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0</code> disables)</li>
<li>Improved "prompt is too long" errors to explain why automatic compaction could not recover instead of only suggesting <code>/compact</code></li>
<li>Improved sandbox: IPv6 literals in network domain lists are now bracketed (<code>[::1]:443</code>), and ambiguous spellings are enforced fail-closed and flagged by <code>/doctor</code></li>
<li>Updated <code>/login</code> to repeat the <code>CLAUDE_CODE_OAUTH_TOKEN</code> override warning after a successful login</li>
<li>Changed <code>/commit-push-pr</code> so git/gh commands with dangerous flags (<code>--force</code>, <code>--amend</code>, <code>--no-verify</code>, etc.) are no longer auto-approved</li>
<li>Changed self-hosted runner Windows startup to require an explicit <code>--base-dir</code>; there is no default checkout directory on Windows</li>
<li>[VSCode] "Report a problem" and <code>/bug</code> now open the built-in feedback dialog instead of a retired survey link</li>
<li>[VSCode] Made the <code>/btw</code> side-question panel resizable by dragging its boundary, in both side-docked and stacked layouts</li>
<li>[VSCode] Added session groups in the sidebar — right-click to create, rename, or delete; Cmd/Ctrl- or Shift-click to move several sessions at once</li>
</ul>
