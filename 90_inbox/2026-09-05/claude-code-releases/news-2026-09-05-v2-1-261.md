## Summary
<h2>What's changed</h2>
<ul>
<li>Added an "Organization policy" line to <code>/status</code> and <code>claude doctor</code> that says why your organization's policy could not be loaded, such as a proxy not passing the endpoint through</li>
<li>Added <code>bashOutputMaxChars</code> and <code>taskOutputMaxChars</code> settings to raise how much command and background-task output Claude receives inline before it is saved to a file, up to 128K characters</li>
<li>Added <code>--append-subagent-system-prompt-file</code> to read the subagent system prompt from a file, for prompts too large to pass on the command line</li>
<li>Added <code>/skill-doctor</code> to show which loaded skills go unused and what they cost in context, so you can prune them</li>
<li>Fixed typed or pasted characters occasionally landing out of order or being dropped during fast input or key repeat</li>
<li>Fixed <code>/add-dir &lt;subdirectory&gt;</code> printing a false "couldn't be resolved" error when the working directory is on a <code>/net</code> automount</li>
<li>Fixed the Bedrock setup wizard hanging when AWS or an AWS credential helper never responds (it now times out with a clear error), and its model checks failing behind a TLS-inspecting proxy</li>
<li>Fixed cloud sessions discarding a plugin synced from claude.ai when managed settings force-enable it in <code>enabledPlugins</code>, then falling back to a marketplace clone that could fail</li>
<li>Fixed being unable to delete the character immediately before an inline <code>[Image #N]</code> chip in the prompt input</li>
<li>Fixed resuming a session losing hook output and other context around parallel tool calls, which changed the resumed request</li>
<li>Fixed Remote Control showing a stale permission mode when a phone, browser, or claude.ai app attaches to a terminal session or after the mode changes in the terminal</li>
<li>Fixed Remote Control sessions showing as still working (stuck spinner and Stop button) after stopping a turn from a connected phone or browser, or after a local slash command like <code>/clear</code></li>
<li>Fixed SDK and cloud sessions ignoring a Stop or interrupt sent just after the first prompt, before the turn had started; the turn now stops instead of running to completion</li>
<li>Fixed Remote Control uploading a session pulled with <code>/teleport</code> into the connected session, which appeared appended to the original on phone and web</li>
<li>Fixed Remote Control's inbound event stream failing behind TLS-inspecting corporate proxies on native Windows</li>
<li>Fixed Remote Control sessions showing the default effort level on claude.ai when the effort comes from settings</li>
<li>Fixed <code>gcpAuthRefresh</code> opening a browser at startup when the Google credential check was slow, even though the credential was still valid</li>
<li>Fixed claude.ai connectors staying absent for the whole session when the startup connector fetch timed out — the CLI now retries in the background</li>
<li>Fixed sustained high CPU usage when a background agent could not be resumed and its wake-up was retried in a tight loop</li>
<li>Fixed feature flags gated to a newer version occasionally applying to an older Claude Code version running on the same machine</li>
<li>Fixed <code>/usage</code> and the VS Code usage panel dropping a model-specific weekly limit row when the usage endpoint is rate limited or when opened right after startup</li>
<li>Fixed <code>claude -p --resume &lt;file&gt;</code> adopting a malformed session ID recorded in the transcript; it now resumes under a fresh session ID instead</li>
<li>Fixed the terminal progress indicator (iTerm2, Ghostty, ConEmu) showing the session as finished while a background workflow or agent was still running</li>
<li>Fixed a rare layout glitch where a box could render with the wrong height after its container switched between row and column direction</li>
<li>Fixed Claude apps gateway client IP when a trusted proxy appends a port to <code>X-Forwarded-For</code>; with an access list set, an unreadable entry now gets 403</li>
<li>Fixed Claude apps gateway telling Claude Desktop to export OpenTelemetry as JSON even when the terminal CLI uses protobuf, so protobuf-only collectors rejected Desktop's data</li>
<li>Fixed Desktop and web showing a session as busy while it only watches an artifact for updates</li>
<li>Fixed Claude in Chrome <code>file_upload</code> failing with "paths: expected array, received undefined" in local Cowork sessions run from the Claude Desktop app</li>
<li>Fixed <code>SendMessage</code> to an offline Remote Control session on another machine reading as delivered; the result now says delivery is queued until that machine reconnects</li>
<li>Fixed plugin install hints from CLIs run in background Bash commands: they are now detected, and the raw <code>&lt;claude-code-hint&gt;</code> tag no longer leaks into the conversation</li>
<li>Fixed in-process agent-team teammates re-sending their first-turn tool and skill announcements on the second turn, which changed the request prefix and missed the prompt cache</li>
<li>Improved the <code>/model</code> picker and the VS Code model pill to show a model's name instead of its raw Bedrock, Vertex AI, or LLM gateway ID when Claude Code recognizes it</li>
<li>Improved startup on Google Vertex AI when <code>GOOGLE_APPLICATION_CREDENTIALS</code> is set: API client creation no longer re-runs Google Cloud project discovery or spawns extra <code>gcloud</code> processes</li>
<li>Improved streaming performance: already-rendered blocks are no longer re-checked by layout on each update</li>
<li>Improved the dangerous-<code>rm</code> safety prompt to also catch <code>rm -rf</code> on positional parameters and inside double-quoted <code>sh -c</code> scripts</li>
<li>Improved handling when the API sends no response headers: the retry now waits up to <code>API_TIMEOUT_MS</code> (10 minutes by default) instead of another 3 minutes, and the messages say what to change</li>
<li>Changed a Claude apps gateway 403 on the managed settings load (at startup or after <code>/login</code>) to say Claude Code may not be enabled for the organization, instead of advising a new sign-in</li>
<li>Changed machines whose managed settings pin <code>forceLoginMethod: "gateway"</code> to ignore a leftover API key or claude.ai login and ask for <code>/login</code>; Bedrock, Vertex AI, and Foundry sessions are unaffected</li>
<li>Changed auto mode to treat a link that packs content into a public diagram renderer's URL as an upload to that site: no longer auto-approved unless you asked for it</li>
<li>Changed the prompt's word-editing keys to match Bash: Ctrl+W deletes back to whitespace, Alt+F and Alt+D stop at word end, punctuation separates words; <code>keybindingFlavor</code> no longer has any effect</li>
<li>Changed <code>/context</code> token counting to use a local estimate when the token-counting API is unavailable, instead of extra small-model requests</li>
<li>[VSCode] Added a "Build a custom style" walkthrough to the Output styles menu that writes a custom output style file and lists it right away</li>
<li>[VSCode] Added an Add server form and a Remove action to the MCP servers dialog, so MCP servers can be added and removed without leaving the IDE</li>
<li>[VSCode] Added a hollow ring in the session list for sessions open in a terminal, another VS Code window, or Claude Desktop, so they no longer look closed</li>
<li>[VSCode] Added a fold button to permission and question prompts so the conversation behind them can be read without dismissing them; the space beside the prompt now scrolls the conversation</li>
<li>[VSCode] Added "Archive session" to the session list's right-click menu and gave Unarchive its own icon</li>
<li>[VSCode] Fixed a session teleported from Claude Code on the web treating a question that was cut off when the cloud session shut down as declined</li>
<li>[VSCode] Fixed the session tab's Rename box opening empty for a tab restored with the window; it now starts with the current name</li>
<li>[VSCode] Fixed collapsed sections in the session list panel briefly showing expanded each time the panel loaded</li>
<li>[VSCode] Fixed Focus view showing a tool call as still running after Claude had moved on, such as while a question waited for your answer</li>
<li>[VSCode] Fixed the session list's active-row highlight going stale when an unfocused Claude tab's session ID is corrected</li>
<li>[VSCode] Fixed Cmd/Ctrl+Shift+T reopen and deep-link opens placing the Claude tab outside the Claude editor group when a Claude tab has focus</li>
<li>[VSCode] Fixed the session tab's "Add to group" putting a session opened from Claude Code on the Web in two groups; it now moves the entry the session list shows</li>
<li>[VSCode] Fixed the model picker showing models an organization has since disabled until the window was reloaded twice</li>
<li>[VSCode] Fixed a tab opened from the session list jumping back to that session, and a tab opened from a Web session restarting its teleport or staying empty, after VS Code reloads the tab's view</li>
<li>[VSCode] Fixed <code>/btw</code> side-question history from earlier sessions being overwritten when a question is asked right after a window reload or while a settings file has errors</li>
<li>[VSCode] Fixed the pending question card not reappearing after the Claude panel reloads when signed in with a Claude.ai or Console account</li>
<li>[VSCode] Fixed claude.ai-only features staying visible in a window's other Claude panels after one panel picked up a third-party provider from a settings file</li>
<li>[VSCode] Fixed the sign-in screen appearing despite the Disable Login Prompt setting when Claude Code reports no login or a request fails for lack of one</li>
<li>[VSCode] Fixed the next queued permission prompt keeping text typed on the previous prompt and accepting an immediate second click</li>
<li>[VSCode] Fixed install-plugin links opening the Claude sidebar without the install dialog in a window where only the session list had been shown</li>
<li>[VSCode] Fixed the sidebar usage meter staying empty on a new window until the Account &amp; usage dialog was opened, and a 0% usage limit being left out of the meter</li>
<li>[VSCode] Fixed "Start new session in this group" losing the group after New conversation, and a missing unread dot for a session that finished before the sidebar's unread list loaded</li>
<li>[VSCode] Fixed the editor tab badge showing unread during a running turn or missing on a tab opened from the session list, and "Add Session Tab to Group" doing nothing for an archived session</li>
<li>[VSCode] Fixed "Enable Remote Control for all sessions" so flipping it also applies right away to sessions open in other VS Code windows</li>
<li>[VSCode] Fixed the session list's Open filter for sessions continued from claude.ai whose tab was still recorded under the web session, and labeled the filter menu's sections for screen readers</li>
<li>[VSCode] Changed the model picker to one flat list of every model, with rows kept for older model spellings listed last</li>
</ul>
