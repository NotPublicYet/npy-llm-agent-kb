## Summary
<h2>What's changed</h2>
<ul>
<li>Added <code>claude plugin eval</code>: run a plugin's eval suite against Claude Code and get scored, reproducible results (JSON + HTML report); see <code>claude plugin eval --help</code></li>
<li>Added <code>/output-style [name]</code> to list and switch output styles, including over Remote Control and in cloud and other headless sessions</li>
<li>Added a diff of the files a Bash command changed to the Bash tool result when the Bash tool handles file edits (setting <code>bashEditDiffEnabled</code>)</li>
<li>Added <code>OTEL_METRICS_INCLUDE_REPOSITORY</code> to tag OpenTelemetry metrics and events with <code>vcs.*</code> repository attributes; commit events get <code>vcs.ref.head.*</code> with <code>OTEL_LOG_TOOL_DETAILS</code></li>
<li>Added <code>CLAUDE_CODE_GATEWAY_MODEL_DISCOVERY_TIMEOUT_MS</code> to extend the LLM gateway <code>/v1/models</code> discovery timeout (default 3s)</li>
<li>Added a spinner tip suggesting <code>/focus</code> for a view with just your prompt, a one-line work summary, and the response</li>
<li>Added <code>CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS</code> (1–256) to raise the Workflow tool's per-run concurrent agent limit for inference-bound fan-outs</li>
<li>Fixed the prompt cache being partially invalidated on the turn after a response was cut off at the output-token limit and automatically resumed</li>
<li>Fixed a case where resuming a session after interrupting Claude mid-thought could change how earlier context was re-sent, hurting prompt-cache reuse</li>
<li>Fixed F1/F2/F4 not working in kitty-protocol terminals and Delete in st, Alt+arrows acting as Escape in rxvt-unicode, and Shift+punctuation typing the unshifted key in WezTerm (regression in 2.1.247)</li>
<li>Fixed remote and headless sessions reporting "waiting for your input" while background agents were still running (set <code>CLAUDE_CODE_BG_TASKS_REPORT_RUNNING=0</code> to restore the old behavior)</li>
<li>Fixed the terminal's replies to capability queries (<code>^[[?1;2c</code>) appearing as stray text at startup in some terminals</li>
<li>Fixed rows at the top or bottom of the transcript going blank in fullscreen after resizing the terminal</li>
<li>Fixed a deny or ask permission rule starting with <code>!</code> applying beyond the settings source that wrote it; such a rule now applies only within its own source, and a bare <code>!</code> negation is ignored</li>
<li>Fixed the git status Claude is told after a compaction: it is now the current status, not the one from the start of the session</li>
<li>Fixed synced plugin MCP servers not connecting when a remote session resumes</li>
<li>Fixed resumed headless sessions losing a turn's replies when the model was switched or a request was retried mid-turn</li>
<li>Fixed terminal escape codes, line breaks and oversized text from a background task's on-disk record reaching the task list and task notifications when work is resumed</li>
<li>Fixed CMYK JPEG images failing to attach with "cannot decode"; they are now converted and resized like other JPEGs</li>
<li>Fixed the managed settings approval dialog not naming the collector for a gRPC telemetry endpoint set without a scheme</li>
<li>Fixed plugin <code>headersHelper</code> consent prompts showing a URL path that could be misread as a different host</li>
<li>Fixed plugin errors showing <code>[redacted URL]</code> in place of a relative Windows path with a folder name that starts with <code>@</code></li>
<li>Fixed missing cursor in the permission-rule, auto-mode-rule, add-directory, session-rename and feedback-review text fields when the terminal's native cursor is enabled</li>
<li>Fixed repeated clicks on a <code>/fork</code> receipt, each under a second apart, never backgrounding the session right away while it waited for the current tool to finish</li>
<li>Fixed plugin LSP servers that reject <code>shutdown</code> params (e.g. rust-analyzer) being left running at session end; <code>exit</code> is now sent even if <code>shutdown</code> fails</li>
<li>Fixed the attribution reminder overriding a CLAUDE.md or memory rule against commit and pull request attribution; lines set by managed settings still apply</li>
<li>Fixed prompt suggestions being dropped for text in Japanese, Chinese, Thai and other languages written without spaces between words</li>
<li>Fixed synchronized output being assumed from the terminal's name in GNOME Terminal and Konsole versions that do not support it</li>
<li>Fixed <code>permission_denials</code> in <code>--output-format stream-json</code> results omitting Read, Edit and Write calls blocked by a path-scoped deny rule</li>
<li>Fixed sessions run through the SDK or the desktop app showing an unknown status in other sessions' agent list</li>
<li>Fixed <code>/insights</code> failing on Bedrock, Vertex, Foundry, and gateway deployments whose account can't reach the default Opus model by using the session model there instead</li>
<li>Fixed organization policy limits not loading for the session when another Claude Code process refreshed the login at the same moment</li>
<li>Fixed Claude Desktop sessions using Bedrock, Vertex, or a gateway not getting the contextual "what Claude needs" turn-end notification text</li>
<li>Fixed MCP servers reconnecting when an updated config only changed the order of the server URL's query parameters</li>
<li>Fixed the prompt box's top border splitting into extra lines when viewing a background agent whose name or description has line breaks or is wider than the terminal</li>
<li>Fixed sessions getting permanently stuck on "Prompt is too long" when auto-compaction had no complete earlier exchange to summarize (mostly Agent SDK sessions with very large prompts)</li>
<li>Fixed <code>/goal</code> runs silently stalling after API errors, network drops, or token limits: the goal now retries with backoff, or pauses and says why, including until a usage limit resets</li>
<li>Fixed prompt cache misses in cloud sessions by waiting briefly for server configuration before the first request</li>
<li>Fixed <code>/btw</code> answers that contained made-up tool calls and output: the side question is now told not to write them, and any that appear are flagged as not executed</li>
<li>Fixed <code>CLAUDE_CODE_RESUME_INTERRUPTED_TURN</code> re-running a turn that had failed with an API error over 6 hours earlier, or longer ago than <code>CLAUDE_CODE_RESUME_INTERRUPTED_TURN_MAX_AGE_MS</code> when set</li>
<li>Fixed organization plugins enabled through managed settings not loading in headless sessions and on Claude Desktop (once Desktop bundles this CLI version); they load from the next session</li>
<li>Fixed plugin archives extracted for a session being readable by other local users, extracted files keeping world-writable bits from the archive, and stale files surviving re-extraction</li>
<li>Fixed <code>Edit()</code> deny rules and the write-path check not applying to the file a Bash <code>tee</code> command writes; a <code>Bash(tee:*)</code> allow rule no longer covers destinations outside the working directories</li>
<li>Fixed stray characters like <code>22c</code>, or a terminal's color or version reply, being typed into the prompt at startup over slow connections (ssh, browser terminals)</li>
<li>Fixed the terminal's block cursor showing under the interface in rxvt-unicode after leaving or re-entering fullscreen</li>
<li>Fixed the cursor block staying visible after returning from an external editor in fullscreen mode on rxvt-unicode</li>
<li>Fixed the interface being drawn twice after returning from an external editor (Ctrl+G) outside fullscreen mode</li>
<li>Fixed the interface being drawn twice in Konsole after returning from an external editor</li>
<li>Windows: Fixed PowerShell tool commands sent to the background stopping when Claude Code exits</li>
<li>Improved the <code>/diff</code> panel to open fully rendered in one step instead of showing a loading state first</li>
<li>Improved prompt suggestion filtering for Japanese, Chinese and Korean text: mixed-script and single-word suggestions are kept, and meta or evaluative text is dropped as it is for English</li>
<li>Improved the Skill tool's "Unknown skill" error to name the plugin skill's full name when a bare name matches exactly one plugin skill</li>
<li>Improved keyboard support over SSH and in unrecognized terminals: terminals that answer the kitty keyboard query (such as foot and Alacritty 0.16+) now get Shift+Enter and Ctrl+Shift shortcuts</li>
<li>Improved responsiveness in long sessions: transcript updates no longer re-process the whole conversation to build the collapsed tool-use summaries</li>
<li>Improved first-party sessions with telemetry disabled: an <code>alwaysLoad</code> MCP server that finishes connecting mid-conversation is usable on the next turn without a tool-search round trip</li>
<li>Changed <code>/ultrareview --post</code> to post the PR comment directly when the findings arrive and print the comment link, instead of starting a second cloud session to post it</li>
<li>Changed artifact database reads that save into the session scratchpad so they no longer stop for working-folder approval</li>
<li>Changed skills synced from claude.ai in cloud sessions to be named <code>anthropic-skills:&lt;name&gt;</code>, matching Claude Desktop; the bare name still works when nothing else uses it</li>
<li>[VSCode] Added an agent map: an "N agents" footer pill opens a map of the session's sub-agents with per-agent cards, Stop agent, and read-only transcripts</li>
<li>[VSCode] Added a Hooks dialog to the command menu for viewing hooks and adding, editing, or removing them in user, project, and local settings; managed, plugin, and session hooks stay read-only</li>
<li>[VSCode] Added live progress rows for running subagents under the tool-call groups in Focus view</li>
<li>[VSCode] Added a Permission rules dialog that lists permission rules and adds or removes them in user, project, and local settings; startup-option, session-only, and managed rules stay read-only</li>
<li>[VSCode] Added a Cancel button to the Switch account screen that returns to your session as the current account</li>
<li>[VSCode] Fixed Focus view showing a turn started by a delivered plain-text prompt, such as a scheduled task's, as part of the previous turn</li>
<li>[VSCode] Fixed the footer's prompt cache clock hiding its minutes when the panel is narrow</li>
<li>[VSCode] Fixed the session list keeping sessions from the default folder when <code>CLAUDE_CONFIG_DIR</code> is set in a settings file or the <code>environmentVariables</code> setting</li>
<li>[VSCode] Fixed a plan preview that finished loading late sometimes hiding its comment box or showing an older plan</li>
<li>[VSCode] Fixed a plan preview accepting comments that went nowhere after its Claude tab closed</li>
<li>[VSCode] Fixed the prompt cache clock and reopen notice for a session compacted after its last reply and then closed, which now reads as cold when reopened</li>
<li>[VSCode] Fixed a session renamed in the extension while Remote Control is on keeping its old name on claude.ai/code</li>
<li>[VSCode] Fixed the "Enable Remote Control for all sessions" toggle keeping its last position after the setting was reset to default from a terminal</li>
<li>[VSCode] Fixed restored Claude tabs not counting as open in the session list after a window reload until clicked, and their row opening a second tab</li>
<li>[VSCode] Fixed Switch account making a tab forget its dismissed usage-limit warnings when you sign back in as the same account</li>
<li>[VSCode] Fixed a session rename being replaced by the generated name after a window reload when the session was renamed during a long turn</li>

<li>[Claude Code on the web] Fixed routine runs that use subagents sometimes being treated as finished too early, which could skip the retry after a real failure or start a duplicate run</li>
<li>[Claude Code on the web] Fixed file links in cloud session transcripts opening a GitHub 404 when Claude was working from a subfolder of the repository</li>
<li>[Claude Code on the web] Changed the Cloud environments admin page to list every environment instead of capping each table at five rows behind a Show more control that could be unreachable</li>
<li>[Claude Code on the web] Changed claude.ai/code for Free-plan users to open the plans page with a path to upgrade, instead of a "Disabled by org admin" page with no way forward</li>
<li>[Claude Tag] Added a confirmation dialog before Connect all or Disconnect on a GitHub installation in admin settings, to guard against accidental organization-wide changes</li>
<li>[Claude Tag] Fixed threads occasionally going silent after a failed turn because the failure notice was dropped when Slack briefly rate-limited it; the notice is now retried</li>

<li>[Claude Tag] Improved scheduled routines in Slack channels: a routine run can now reply in an existing thread instead of always posting a new top-level channel message</li>
