## Summary
<h2>What's changed</h2>
<ul>
<li>Added <code>CLAUDE_CODE_AUTO_MODE_MODEL</code> to choose the model the client-side auto mode classifier uses; it does not change the model for server-side auto mode</li>
<li>Added an <code>Idle compaction</code> row to <code>/config</code> for turning idle compaction off or back on; the notices shown after an idle compaction now say how to turn it off</li>
<li>Added a notice to <code>/design-sync</code> and <code>/design-login</code> that standalone Claude Design (claude.ai/design) closes by December 14, 2026</li>
<li>Fixed a "Prompt is too long" error when stopping a turn while the conversation was being compacted</li>
<li>Fixed requests failing with "diagnostics: Extra inputs are not permitted" after switching to Vertex or Bedrock mid-session</li>
<li>Fixed the Read tool loading an image file of any size, or a pipe or device named like an image, entirely into memory; image sources over 128 MB are now refused</li>
<li>Fixed <code>/autocompact</code> and <code>/effort</code> saving to the wrong model when a gateway names Opus 4 or 4.1 with a prefix, such as <code>anthropic/claude-opus-4-1</code></li>
<li>Fixed a prompt cache miss when a tool added mid-session was loaded again through ToolSearch or after compaction</li>
<li>Fixed <code>claude plugin</code> and other subcommands sometimes exiting before a queued settings or config write finished, which could lose the change or leave a <code>.tmp</code> file behind</li>
<li>Fixed plugin marketplaces re-cloning on every refresh, and newly installed git plugins showing version "unknown", when git defaults to the reftable ref format</li>
<li>Fixed the PowerShell tool not finding commands in a plugin's <code>bin/</code> folder, and reporting an error when a search that finds nothing (rg, grep, findstr, git grep) is piped into <code>Select-Object</code> or another formatting cmdlet</li>
<li>Fixed Claude in the desktop app pointing you to claude.ai settings or <code>/mcp</code> to authorize or reconnect an MCP server where that option isn't available</li>
<li>Fixed artifact publishes sometimes failing when Claude sent an empty list of edits, and Claude retrying an artifact update the wrong way after a newer version of the artifact turned it away</li>
<li>Fixed <code>classifier_category</code> missing from OpenTelemetry <code>tool_decision</code> events for most auto mode classifier blocks, and new <code>tool_decision</code> attributes pushing out <code>tool_use_id</code>, <code>tool_source</code> and <code>tool_parameters</code> when <code>OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT</code> is low</li>
<li>Fixed rows in the agents view staying blank after moving down a long list or folding a section</li>
<li>Fixed <code>claude remote-control --help</code> not printing its usage and exiting when not signed in</li>
<li>Fixed <code>/design consent</code> and <code>/design revoke</code> suggesting <code>/design-login</code> when they fail in a cloud session, where it isn't available; the message now points to claude.ai/design/settings</li>
<li>Fixed MCP servers showing no tools, or every tool call failing, when the server negotiates protocol version 2026-07-28 but omits <code>resultType</code>, <code>ttlMs</code> or <code>cacheScope</code></li>
<li>Fixed prompt suggestions spending usage credits on models your plan pays for only with credits: they are now skipped after a reply billed to credits</li>
<li>Fixed URLs written in backticks being clickable only on their first row when they wrap; the whole URL is now one link in terminals that support hyperlinks</li>
<li>Fixed <code>claude plugin details &lt;name&gt;@builtin</code> suggesting <code>claude plugin list</code>, which never shows built-in plugins, when the plugin isn't found; it now points to <code>/plugin</code></li>
<li>Fixed an emoji that a link starts inside wrapping one column too wide, which hid it in question previews and turned tables into lists</li>
<li>Fixed worktree isolation refusing to create or resume worktrees under git 2.56 or later when a stray <code>.git</code> file points at a directory that doesn't exist</li>
<li>Fixed a cloud session's cost and usage restarting from zero after the session resumed in a new process</li>
<li>Self-hosted runner: Fixed git fetches failing with "bad object refs/heads" in sessions that reuse a checkout stored in git's reftable format</li>
<li>Windows: Fixed every file write being refused or asked about for projects on exFAT or FAT32 drives, including in sessions started with <code>--plugin-dir</code></li>
<li>Improved startup time with many plugins enabled: plugin command and agent files now take far fewer file system calls to load, most of all on Windows</li>
<li>Improved auto mode with the server-side classifier: a conversation too long for the safety check is now compacted, instead of every checked tool call being denied</li>
<li>Improved the message when a background session reopened from another folder has no LLM gateway: it now says why, instead of "Not logged in"</li>
<li>Changed <code>claude -p</code> and Agent SDK sessions with no permission mode to start in <code>default</code> mode on third-party providers, with telemetry off or on a fresh install; <code>--permission-mode auto</code> keeps auto</li>
<li>Changed fork subagents (<code>subagent_type: "fork"</code>) to be on by default in <code>claude -p</code>, the Agent SDK, the desktop app and VS Code, as they already are in the terminal; <code>CLAUDE_CODE_FORK_SUBAGENT=0</code> turns them off, and <code>claude mcp serve</code> never offers them</li>
<li>Changed the desktop app and VS Code to always run the main conversation's subagents in the background, as the terminal does, rather than let Claude choose; a subagent's own Agent calls in <code>claude -p</code>, the Agent SDK, the desktop app and VS Code now run in the foreground by default</li>
<li>Changed the <code>← for agents</code> footer hint to hide 10 seconds after a session opens; the count of agents waiting on you still shows</li>
<li>Changed where the Claude in Chrome instructions sit in the system prompt so that new conversations can read them from the shared prompt cache</li>
<li>Changed prompt and agent hooks so that at most 12 of one event run at a time; the rest wait their turn</li>
<li>Changed the message shown when your organization's policy turns off <code>/feedback</code>: it now points to GitHub issues instead of an organization admin</li>
<li>[VSCode] Fixed text after an unclosed code block in a list showing as plain text while a reply streams, then turning into code</li>
<li>[VSCode] Fixed MCP server sign-in from the panel opening a broken authorization page when the server URL contains a query string</li>
<li>[VSCode] Fixed the <code>@browser</code> banner saying "Browser connected" when no browser with the Claude extension can be reached</li>
<li>[Cloud sessions] Added a banner on a routine's page that says why its last run didn't start, such as your organization reaching its limit on concurrent cloud sessions</li>
<li>[Cloud sessions] Fixed "Rewind to here" failing on every message except the newest in cloud sessions; self-hosted runners need Claude Code v2.1.246 or later</li>
<li>[Cloud sessions] Fixed the pull request status bar in cloud sessions flipping a pull request with merge conflicts back to ready while GitHub rechecked it</li>
<li>[Cloud sessions] Fixed routine runs showing as Completed after their cloud session stopped unexpectedly, and as Cancelled when archived before they started, instead of failed</li>
<li>[Cloud sessions] Fixed the diff view in cloud sessions missing changes or failing to load after the session's GitHub repository was renamed or moved</li>
<li>[Cloud sessions] Fixed a scheduled routine run that failed partway being run again from the start an hour or more later, which could repeat work such as posting the same report twice</li>
<li>[Cloud sessions] Fixed an open cloud session sometimes not showing messages sent from another device until you reloaded the page or clicked away and back</li>
<li>[Cloud sessions] Improved the error shown when a cloud session fails to start: it now says "Connection lost" or "Server error" instead of "Something went wrong"</li>
<li>[Remote Control] Fixed a subagent's pane spinning forever in a Remote Control session after your computer goes offline; it now says Remote Control is disconnected</li>
<li>[Claude Tag] Fixed "is thinking…" staying up under a mention in a Slack channel or DM after Claude answered it by editing one of its earlier messages</li>
<li>[Claude Tag] Fixed URLs in code blocks under a numbered or bulleted step of Claude's Slack replies being wrapped in angle brackets, which broke copied commands</li>
<li>[Claude Tag] Fixed HEIC, SVG, TIFF and BMP images attached in Slack never reaching Claude; they now arrive as files in its working files, like other file types</li>
<li>[Claude Tag] Fixed new channel managers losing access to Claude in Slack in organizations that restrict Claude Tag by role; the manager role now also grants Claude Tag in Slack</li>
<li>[Claude Tag] Fixed custom connectors whose MCP servers share one host showing as a single connector in Claude Tag admin settings; each server is now its own connector</li>
<li>[Claude Tag] Fixed Claude in Slack sometimes answering a direct message with "DMs are temporarily unavailable" and dropping it when a single Slack lookup stalled; it now retries first</li>
<li>[Claude Tag] Fixed direct messages with Claude on a Slack Enterprise Grid ignoring Slack's workspace dropdown; they now run under the connected workspace you last opened Claude in</li>
<li>[Claude Tag] Fixed Claude in Slack's notice for a channel's monthly spend limit saying a channel manager can raise it; it now names an organization owner and links the usage page</li>
<li>[Claude Tag] Fixed links in Claude's Slack replies absorbing the closing bold or italic marks, or full-width punctuation, right after them, which broke the link and the formatting</li>
<li>[Claude Tag] Improved repository search in Claude Tag admin settings to cover up to 100 connected GitHub accounts and find private repositories past the first 5,000 of a GitHub App install</li>
<li>[Claude Tag] Improved Add place in Claude Tag admin settings to list a channel you type or paste right away, instead of only after your organization's full channel list has loaded</li>
<li>[Claude Tag] Improved Add &gt; Domain on a workspace's or channel's page in Claude Tag admin settings to be available once that page loads, not only after every channel has loaded</li>
<li>[Claude Tag] Changed Claude Tag admin settings to organize Claude's access into four tabs: Bundles, Connectors, Skills and plugins, and Channels</li>
<li>[Claude Tag] Changed the Roles page in organization settings to group the roles created for Claude Tag channel managers in a collapsed section below your organization's own roles</li>
<li>[Code Review] Fixed Code Review setup not resuming after you leave to connect GitHub; back in admin settings, it now reopens at the repository picker</li>
</ul>
