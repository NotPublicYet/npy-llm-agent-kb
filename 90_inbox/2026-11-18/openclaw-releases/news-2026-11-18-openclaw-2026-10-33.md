## Summary
<p>This is a gateway-only <code>extended-stable</code> release, which is our current equivalent to LTS. This release is OpenClaw from the end of October 2026, plus critical security updates, reliability and performance fixes, and features like new model support. The latest version of OpenClaw at the time of this release is <a href="https://github.com/openclaw/openclaw/releases#release-v2026.11.5">2026.11.5</a></p>
<h2>2026.10.33</h2>
<p>This extended-stable release brings cumulative Gateway and core-plugin improvements since 2026.9.37, plus the selected maintenance fixes on the approved 2026.11.4 product baseline. Distribution covers the core npm package, matching official npm plugins, and Gateway Docker images; native-app releases are not included.</p>
