## Summary
<h2>What's changed</h2>
<ul>
<li>Added the Monitor tool and plugin monitors on Bedrock, Vertex, and Foundry, and when telemetry or nonessential traffic is disabled; long foreground sleeps are now blocked there too</li>
<li>Fixed requests failing behind some gateways and compatible servers that reject the <code>effort-2025-11-24</code> beta value or mid-conversation system messages; Claude Code now retries without them</li>
<li>Fixed background cleanup deleting some recent files, such as pasted images, when <code>cleanupPeriodDays</code> is set to a very large value</li>
<li>Fixed compaction after a "Prompt is too long" error keeping too much of a conversation with dense text, such as base64 or SVG, so the next request could fail again</li>
<li>Fixed file read permission prompts not showing where a symbolic link leads</li>
<li>Fixed a question's auto-continue timeout firing the moment the external editor closed after a long edit</li>
<li>Windows: Fixed PreToolUse and PermissionRequest hooks letting a tool call through when Git Bash is missing and the hook's command is only quoted strings, such as a quoted path</li>
<li>Improved auto mode's prompt before the first read outside the working directories: it now says when blocking those reads makes shell commands ask for permission</li>
<li>Improved memory use of non-interactive sessions (<code>-p</code>, Agent SDK) during compaction when the transcript file is very large</li>
<li>Improved a mod's <code>Image</code> to draw inside tmux with <code>allow-passthrough</code> and <code>focus-events</code> on, in kitty, Ghostty, and iTerm2 3.5+ with fullscreen rendering, where it showed only its <code>alt</code> text</li>
<li>Linux: Improved <code>/sandbox</code> and the sandbox startup warning to name Ubuntu's AppArmor restriction on user namespaces, and how to lift it, when it keeps bubblewrap from starting the sandbox</li>
<li>Changed the error for an MCP tool call that times out in a non-interactive session while the server's elicitation is unanswered: it now tells Claude that no answer came and not to repeat the call</li>
<li>[VSCode] Fixed pressing Enter on the plan review card's "Send feedback and keep planning" button approving the plan instead of sending your comments back</li>
<li>[VSCode] Fixed the panel showing "Something went wrong" after "Switch branch &amp; continue" on a cloud session opened from Session history's Web tab</li>
<li>[Cloud sessions] Added Claude Code cloud sessions and Remote Control permissions to Enterprise custom roles, so Owners can control access to each by role</li>
<li>[Cloud sessions] Added a Choose file button to load a cloud environment's setup script from a file</li>
<li>[Cloud sessions] Fixed failed saves and archives in the cloud environment edit dialog showing no error inside the dialog</li>
<li>[Cloud sessions] Fixed failed routine API token actions showing only a toast; the error now appears in the routine edit dialog</li>
<li>[Cloud sessions] Improved the session start checklist to show a cloud environment's setup script output in a scrolling box</li>
<li>[Cloud sessions] Changed turning on Cloud sessions or Remote Control in admin settings to ask for confirmation and list the custom roles that have that permission</li>
<li>[Cloud sessions] Changed the cloud environment dialog to open network access, setup script and environment variables from rows instead of listing every editor at once</li>
<li>[Claude Tag] Fixed Claude Tag treating <code>!</code> commands such as <code>!restart</code> and <code>!help</code> as ordinary messages when sent in bold, italic or strikethrough</li>
<li>[Claude Tag] Fixed Claude Tag admin channel and workspace pages being replaced by a load error when a background refresh of the bundle list fails</li>
<li>[Claude Tag] Fixed Claude Tag's spend limits page in admin settings reporting that no channels match a filter while channel names are still loading</li>
<li>[Code Review] Fixed the Code Review admin section hiding its repositories and switches after a failed refresh of the repository list</li>
<li>[Code Review] Improved the Code Review admin section to retry the first load and show one Try again banner when it still fails</li>
</ul>
