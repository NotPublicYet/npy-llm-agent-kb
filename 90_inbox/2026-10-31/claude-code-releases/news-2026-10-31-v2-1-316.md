## Summary
<h2>What's changed</h2>
<ul>
<li>Added <code>CLAUDE_CODE_DISABLE_ULTRATHINK</code>, which turns the <code>ultrathink</code> keyword off</li>
<li>Added pooled group budgets to the Claude apps gateway: one monthly budget that a group's members share, on top of each member's own limit, set with <code>pooled_budget</code> on the spend limits admin API</li>
<li>Added <code>CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP</code> to keep system cross-certificates that certify each other in a loop, for servers whose private CA needs one</li>
<li>Added <code>CLAUDE_CODE_SUBAGENT_EFFORT</code> to set the effort level subagents run at when nothing else names one, instead of inheriting the session's</li>
<li>Added <code>managed.policy_mode: layered</code> to the Claude apps gateway: every policy that matches a developer applies, each merged over the ones listed below it, not only the first</li>
<li>Added <code>guardrail.input_tagging</code> on Claude apps gateway Bedrock upstreams, which wraps prompts in the input tags that an Amazon Bedrock guardrail's prompt attacks filter needs; <code>all_messages_and_system</code> also tags the system prompt</li>
<li>Deprecated fast mode for Opus 4.8 as of October 30, 2026; it will be removed on November 30, 2026. After removal, fast mode requests on Opus 4.8 return an error and do not fall back to standard Opus 4.8. Migrate to Opus 5.5 to keep the speedup</li>
<li>Fixed shell commands being left running on macOS and Linux when Claude Code exits by itself, for example when credentials are refused or a cloud session is archived</li>
<li>Fixed bash aliases with line breaks in their value (except in Git Bash), and functions whose names start with a dash, being garbled or lost in the Bash tool's shell</li>
<li>Fixed bash scripts started from the Bash tool stopping after their first command when <code>SHELLOPTS</code> is exported</li>
<li>Fixed PowerShell hooks not blocking on exit code 2 when the command begins with a type cast, <code>param</code>, <code>using</code> or an attribute</li>
<li>Fixed some network requests hanging when a compressed response was cut off or corrupted</li>
<li>Fixed <code>sonnet</code>, <code>opus</code> and <code>haiku</code> on Vertex AI and Amazon Bedrock showing an error mid-session instead of switching to an older model when the newest is not yet available to the account or region</li>
<li>Fixed the Claude apps gateway not checking every model a request names against <code>availableModels</code>, <code>deniedModels</code> and <code>models</code>; a request that names a blocked model now gets a 400 naming the field</li>
<li>Fixed <code>claude auth login</code> refusing to run where managed settings require a Claude apps gateway; in a terminal it now shows the gateway sign-in</li>
<li>Fixed <code>--restricted</code> sessions uploading files from outside the working directories when a Read allow rule covered them</li>
<li>Fixed prompts containing invisible characters needing a second Enter to send; plain prompts now send cleaned on the first Enter, and commands still wait for review</li>
<li>Fixed sub-agents that inherited a parent sub-agent's model moving to the main model when a background job or message woke them</li>
<li>Fixed a managed <code>autoMode.allow</code> list without <code>"$defaults"</code> getting the built-in exceptions back from a host app's <code>--settings</code>, a first rule added in <code>/permissions</code>, or <code>/auto-mode-setup</code></li>
<li>Fixed cloud sessions and cloud scheduled tasks not being marked as failed when auto mode stopped a turn because the server returned no safety verdict</li>
<li>Fixed <code>claude -p</code> text output sometimes not saying why auto mode stopped a turn when a background agent was still running</li>
<li>Fixed <code>CLAUDE_CODE_AUTO_MODE_SERVER=1</code> being ignored in sessions started by a host application (such as Claude Desktop) behind a proxy or LLM gateway with experimental betas turned off</li>
<li>Fixed plugin MCP <code>headersHelper</code> scripts receiving a corrupted <code>CLAUDE_PLUGIN_ROOT</code> and server URL when a credential-named environment variable was set to a switch value such as <code>1</code></li>
<li>Fixed the SDK <code>register_repo_root</code> control request not loading the CLAUDE.md of a directory outside the working directory (with <code>CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1</code>)</li>
<li>Fixed the Artifact tool showing <code>?</code> for artifact database access rules at the <code>self</code> level, and not quoting those rules back when it refuses a republish that would drop them</li>
<li>Fixed <code>/model &lt;id&gt;</code> not warning when the model isn't recognized by this version and auto-compact will assume a 200K context window</li>
<li>Fixed the "hold space to speak" hint using up its three showings in one session, and showing an empty key when push-to-talk is unbound</li>
<li>Fixed Grep and Glob never returning when the search process is killed at the timeout but does not exit, seen on Windows</li>
<li>Fixed a rare case where resuming a conversation did not restore its plan, when <code>/clear</code> or <code>/resume</code> had been run while part of that conversation was still being saved</li>
<li>Fixed first-run setup dropping words from the security notes and the terminal-setup explanation in narrow terminals</li>
<li>Fixed the Enterprise survey card taking a typed 1 or 0 after a short pause; a typed answer now needs Enter</li>
<li>Self-hosted runner: Fixed a message sent while Claude was working being answered after a Stop, once the session's process had been replaced</li>
<li>Self-hosted runner: Fixed an MCP server's on/off switch sometimes being lost when a session moved to a new machine</li>
<li>Windows: Fixed the Bash tool losing your aliases and functions in Git Bash when the rc file sets errexit and pipefail and only winpty aliases, or none, are defined</li>
<li>Improved <code>/code-review</code> started from the Code tab in Claude Desktop or on the web: cloud and <code>claude remote-control</code> sessions now show the findings card, not a plain-text list</li>
<li>Improved <code>/diff</code> on large repositories: each refresh usually runs one fewer full-repository git command, and refreshes are spaced out when git is slow</li>
<li>Improved the messages shown when <code>/ultrareview</code>, a cloud session or a cloud agent finds no GitHub remote: they now say to create a repository at <a href="https://github.com/new">https://github.com/new</a>, and <code>/ultrareview</code> no longer suggests a <code>gh</code> command that <code>gh</code> rejects</li>
<li>Improved SSL certificate errors to name the likely causes, among them a server that leaves out an intermediate certificate, and the fix for each</li>
<li>Changed auto mode so that an <code>autoMode.allow</code> list without <code>"$defaults"</code> no longer removes the built-in rule on scheduled-task prompts</li>
<li>Changed server-managed settings for Team and Enterprise logins: settings fetched from Anthropic's API now apply without an approval prompt, and a stored copy that doesn't verify is refused</li>
<li>[VSCode] Added sign-in to a Claude apps gateway from the chat panel, with no terminal needed</li>
<li>[VSCode] Changed <code>ultrathink</code> to run its turn at <code>xhigh</code> effort and show in a rainbow in the chat box, as in the terminal</li>
<li>[VSCode] Fixed the missing Effort slider, Ultracode switch and model name when the model setting has the <code>[1m]</code> tag, such as <code>opus[1m]</code></li>
<li>[VSCode] Fixed saved <code>/btw</code> side-question history being deleted too early while a settings file has errors</li>
<li>[VSCode] Fixed a conversation coming back in Auto mode after a reload or restart when its plan was approved with "Yes, and manually approve edits"</li>
<li>[Cloud sessions] Added a form card to cloud sessions, so you can fill in or decline a form an MCP server asks for instead of the request being canceled without you seeing it</li>
<li>[Cloud sessions] Added a "Catching up…" line that shows while a cloud or Remote Control session you switch back to is still bringing its messages up to date</li>
<li>[Cloud sessions] Changed network secrets so Enterprise members can add and delete them on their own cloud environments, instead of only viewing them</li>
<li>[Cloud sessions] Improved the Changes pane for cloud sessions: the note about what the list leaves out is now a badge beside the branch name, not a row above the diff</li>
<li>[Cloud sessions] Fixed file search in a cloud session's Files pane showing folders as ../.. paths after Claude changed directory; results now show their path from the project's root</li>
<li>[Claude Tag] Fixed Claude refusing to edit or append to a canvas it made in a Slack channel, from that channel, once the canvas was also shared to another channel or a DM</li>
<li>[Claude Tag] Fixed untagged replies going unanswered in a Slack Connect thread when both organizations have installed Claude and Slack delivered the reply to the other organization's app</li>
<li>[Claude Tag] Fixed a cloud scheduled task's live status checklist in Slack staying half-done; a run can now edit the top-level messages it posted during that run</li>
<li>[Claude Tag] Changed a Slack channel's Respond automatically switch to a "How Claude participates" choice on the channel's Configure page and in Claude Tag admin settings</li>
<li>[Code Review] Added a findings-by-severity card to the Code Review analytics page, showing the period's total findings, a daily chart stacked by severity, and each severity's count</li>
</ul>
