## Summary
<h2>What's changed</h2>
<ul>
<li>Added a <code>maxProseWidth</code> setting that caps the width of Claude's prose in wide terminals while tables and code blocks keep the full width</li>
<li>Added a startup notice, and <code>/status</code> and <code>claude doctor</code> entries, listing telemetry variables in a project's settings files that were ignored or that turned telemetry off</li>
<li>Added the <code>allowClaudeInChromeWithManagedMcp</code> managed setting to let <code>claude --chrome</code> run alongside an exclusive <code>managed-mcp.json</code>; the error shown when Chrome is blocked now names it</li>
<li>Added <code>store.readiness_grace_seconds</code> to the Claude apps gateway so <code>/readyz</code> can stay ready through a short Postgres outage such as a database failover</li>
<li>Added a scrollbar to the <code>/feedback</code> drafts list in fullscreen mode; it appears while the mouse is over the list</li>
<li>Fixed every request failing with a 400 error in conversations whose history holds web search results the API cannot decrypt (for example, from a turn answered through a third-party gateway)</li>
<li>Fixed more cases of continued or resumed sessions (<code>--continue</code>, <code>--resume</code>) re-sending earlier messages in a changed form, which could make the API drop Claude's earlier reasoning</li>
<li>Fixed earlier extended thinking being dropped when <code>/model</code>, <code>/rename</code>, <code>/artifacts</code> or another immediate slash command was used while Claude was working</li>
<li>Fixed continued or resumed conversations losing earlier extended thinking when relaunched with a <code>--tools</code> list that leaves out a built-in tool offered earlier in the conversation</li>
<li>Fixed sessions failing on every turn with an "Invalid <code>data</code> in <code>redacted_thinking</code> block" API error; Claude Code now drops the conversation's thinking blocks and retries once</li>
<li>Fixed compaction failing when the summarization request is refused; it now retries on a fallback model</li>
<li>Fixed a failed turn ("Effort 'xhigh' isn't available with thinking turned off") after a safety-related model switch in sessions with thinking off and effort above high</li>
<li>Fixed an unanswered Fable usage-credits prompt switching models in SDK-hosted sessions such as Claude Desktop; the turn now ends instead, and Remote Control clients now see the model-switch notice</li>
<li>Fixed <code>/model</code> with a full Fable model id stopping at an API error instead of opening the usage-credits prompt when the plan needs usage credits that aren't turned on yet</li>
<li>Fixed requests failing for up to a minute with an "another Claude Code process is refreshing it" login error after that other process was closed or killed mid-refresh</li>
<li>Fixed sessions started while another Claude Code window was refreshing the sign-in (common with several VS Code windows) not retrying their organization policy fetch</li>
<li>Fixed CLAUDE.md and rules being read at startup through a repository symlink reaching macOS's <code>/Network</code> via <code>..</code> or a <code>/.vol</code>-style kernel path, or a rules link to macOS's <code>/home</code> being listed</li>
<li>Fixed Bash permission rules with a mid-pattern <code>:*</code> being skipped in settings files while <code>--allowedTools</code> honored them; they now work from every source, with a startup warning on how they match</li>
<li>Fixed a command approved on a restored permission prompt running twice when a remote session's worker restarted</li>
<li>Fixed managed settings ignoring a mistyped value for boolean lock keys such as <code>disableClaudeAiConnectors</code> or <code>allowManagedPermissionRulesOnly</code>; the lock now applies and startup names the key</li>
<li>Fixed managed <code>permissions</code>, <code>autoMode</code>, <code>worktree</code> and <code>attribution</code> settings being ignored entirely when one nested value was invalid; the rest of the block now still applies</li>
<li>Fixed repository, user and <code>--add-dir</code> skills, commands and skills-directory plugin manifests pre-approving their own tools via <code>allowed-tools</code> under managed <code>allowManagedPermissionRulesOnly</code></li>
<li>Fixed safeguard block messages on Amazon Bedrock and Bedrock Mantle not showing a request ID; block messages now also show the message ID</li>
<li>Vertex AI: Fixed web search not being offered for models Claude Code doesn't recognize yet, such as newly released ones</li>
<li>Fixed Bash and PowerShell hiding a full disk quota behind "Exit code 1" and leaving large output files in temp</li>
<li>Fixed tool input validation errors naming only an unknown, missing or mistyped parameter when other parameters in the same call were also invalid; those are now listed too</li>
<li>Fixed pasted multi-line text being submitted line by line after the terminal's bracketed paste mode was reset mid-session</li>
<li>Fixed the prompt's example text flashing and disappearing at startup in projects with a <code>SessionStart</code> hook</li>
<li>Fixed a blank screen flashing before the first frame when starting in fullscreen mode</li>
<li>Fixed garbled, misplaced rows in the non-fullscreen renderer after the screen got shorter while still taller than the terminal, e.g. deleting a prompt line while a shell command streams output</li>
<li>Fixed a stale character left in the last column of a diff when a redrawn line's CJK character or emoji wrapped to the next row</li>
<li>Fixed the cursor landing before the end of a prompt recalled from history when the prompt contains a tab</li>
<li>Fixed the send-now hint showing ctrl+enter on terminals that send it as a newline (Windows Terminal before 1.25); it now shows ctrl+x ctrl+s there</li>
<li>Fixed <code>claude remote-control --debug</code> failing with "Unknown argument: --debug", although Remote Control's own eligibility error says to run with <code>--debug</code></li>
<li>Fixed <code>/install-github-app</code> saying "cancelled" and then still pushing the branch and saving the API key secret; leaving now stops the remaining steps and reports what was already done</li>
<li>Fixed /feedback, /bug and /share on Bedrock, Vertex and other third-party providers still saving the report file after you cancelled during the save</li>
<li>Fixed plugin uninstall reporting success and deleting the plugin's saved options when its settings file still enabled it or could not be read; it now stops and names the file</li>
<li>Fixed plugin uninstall deleting a plugin's saved options and secrets when the list of installed plugins could not be read after the removal; they are now kept and the uninstall says so</li>
<li>Fixed a key typed right after <code>/</code> in <code>/skills</code> moving the skill list instead of reaching the search box</li>
<li>Fixed the terminal cursor jumping from the <code>/skills</code> search box to the skill list while typing, which could hide the caret and put IME input in the wrong place</li>
<li>Fixed lists with a scrollbar, such as <code>/skills</code> and <code>/mcp</code>, being two columns narrower outside fullscreen mode, where the scrollbar can never appear</li>
<li>Fixed the agent panel footer wrapping onto two lines with long rebound keys, and its "Esc to collapse" hint ignoring a rebound collapse key</li>
<li>Fixed a doubled <code>·</code> separator in the <code>/tasks</code> dialog footer when the stop-all-agents shortcut is unbound in <code>keybindings.json</code></li>
<li>Fixed artifact publishes failing when Claude gave the version a label longer than 60 characters; the label is now shortened</li>
<li>Fixed screen-reader mode, quoted lists and very long lists dropping the blank lines at the top of a code block that opens a list item, directly or inside a quote</li>
<li>Fixed PDF page-read error messages: paths with accented or non-Latin characters now appear readably, and a folder named like "password" or "invalid" can no longer make the error name the wrong cause</li>
<li>Fixed vim mode <code>&gt;&gt;</code> indenting empty lines, <code>r</code> with a count longer than the line changing text, <code>2J</code> joining one line too many, and a count on the last line (<code>2dd</code>, <code>2&gt;&gt;</code>) shifting or deleting it</li>
<li>Fixed vim mode cursor placement: after <code>dd</code>, <code>dj</code>, <code>dG</code> or a whole-line <code>p</code>/<code>P</code> it lands on the first non-blank, <code>yy</code> no longer moves it, and Esc after an emoji no longer leaves it inside the emoji</li>
<li>Fixed vim mode ignoring a count typed before <code>.</code> when repeating <code>x</code>, <code>s</code>, <code>p</code>, <code>d</code> or <code>c</code>, and whole-line <code>p</code>/<code>P</code>, <code>o</code>, <code>O</code>, <code>J</code>, <code>&gt;&gt;</code> and <code>&lt;&lt;</code> acting on the wrong line when a line above wraps</li>
<li>Fixed vim mode leaving the cursor past the end of a prompt recalled from history or pulled back from the queue in normal mode, so <code>x</code> did nothing</li>
<li>Improved the time to resume very large sessions, including ones that were never compacted</li>
<li>Improved the error shown on Windows when a session can't be resumed because its transcript file could not be read (EBADF): it now names possible causes and what to try</li>
<li>Improved the Claude Desktop unknown-model error to suggest switching to a different model</li>
<li>Improved rendering of unusual Unicode in permission prompts</li>
<li>Improved <code>/artifacts</code>: titles line up in one column, details are dropped whole instead of cut mid-word, and the list supports PgUp/PgDn, Home/End, the mouse wheel and clicks</li>
<li>Updated the <code>claude-api</code> skill: pre-output refusal billing now links to the How refusals are billed docs, mid-stream refusals bill at normal rates, and pre-output refusals count against rate limits</li>
<li>Updated the <code>claude-api</code> skill to recommend <code>ant apply</code> for keeping Managed Agents resources as version-controlled files</li>
<li>Changed auto mode to use the server-side classifier by default on a direct Anthropic API connection when telemetry is off (<code>CLAUDE_CODE_AUTO_MODE_SERVER=0</code> opts out)</li>
<li>Changed <code>sandbox.excludedCommands</code> to ignore project and local settings entries when managed settings or <code>--settings</code> set <code>allowUnsandboxedCommands: false</code>, or managed <code>allowManagedDomainsOnly: true</code></li>
<li>Changed project and local settings to ignore OpenTelemetry variables that turn on export, set its endpoint, or capture content, like <code>CLAUDE_CODE_ENABLE_TELEMETRY</code> and <code>OTEL_LOG_*</code></li>
<li>Changed Windows/WSL managed settings so an admin policy that is present but invalid or unreadable (HKLM, <code>managed-settings.json</code>) keeps user-writable HKCU and WSL <code>/etc/claude-code</code> from applying</li>
<li>Changed <code>Skill(anthropic-skills:*)</code> and <code>Skill(claude-ai:*)</code> allow rules to cover only skills synced from claude.ai, not plugins or other skills that merely use such a name</li>
<li>Changed skill folders, command files and workflow commands in the <code>anthropic-skills</code> or <code>claude-ai</code> namespace to no longer load; a plugin so named still loads but yields name ties to synced skills</li>
<li>Changed MCP servers configured under the name <code>anthropic-skills</code> or <code>claude-ai</code> to list no skills or prompts (their tools still work); rename the server in your MCP configuration to list them again</li>
<li>Changed the <code>ultracode</code> visuals in <code>/effort</code> and the prompt input to plain styling (no ripple, border flourish or keyword glimmer) and removed the dynamic-workflows spinner tip</li>
<li>Changed the Clawd mascot's feet in the start-up banner to sit under the corners of his body</li>
<li>[VSCode] Fixed long replies falling behind the stream: the panel no longer re-parses the whole reply on every update</li>
<li>[VSCode] Fixed the dictation mic button covering the message input's scrollbar when the input is tall enough to scroll</li>
<li>[VSCode] Fixed Remote Control sessions started on this computer not opening from their Web entry in the session list; they now open the local conversation unless it's running elsewhere</li>
<li>[VSCode] Fixed an editor tab's sign-in screen hanging silently after the extension host restarts; it now shows the "stopped responding" notice too</li>
<li>[Cloud sessions] Added Claude GitHub App status to Settings › Connectors › GitHub: whether the app is installed and reachable for your account, plus steps to connect, install or reconnect</li>
<li>[Cloud sessions] Added "Open repository" and "Open compare page" links to the repository menu of a cloud session whose repository is hosted on a Git server other than GitHub</li>
<li>[Cloud sessions] Added attaching a repository from a different GitHub owner, such as a fork's upstream, to a running cloud session that already has one, including sessions started from Slack</li>
<li>[Cloud sessions] Fixed the next run time shown for an hourly routine being 30 minutes off for people in half-hour-offset time zones such as India</li>
<li>[Cloud sessions] Improved how quickly the Routines page and the sidebar's Scheduled list load for accounts whose past sessions scheduled many check-in reminders</li>
<li>[Claude Tag] Fixed auto-join channel patterns saved for one workspace in Claude Tag admin settings being ignored on an Enterprise Grid org-wide install; Claude now joins matching new channels</li>
<li>[Claude Tag] Fixed Claude not responding in an Enterprise Grid channel shared between two workspaces of one organization when the channel's Claude Tag version was saved from the other workspace</li>
<li>[Claude Tag] Fixed the earlier Claude in Slack app's progress card for sessions on a GitHub Enterprise Server repository: it now names the repository and offers a working Create PR button</li>
<li>[Claude Tag] Fixed Slack threads whose model has been retired falling back to another model on every reply, slower and with a fallback note each time; the thread now moves to a working model</li>
<li>[Claude Tag] Fixed files Claude uploads to Slack not being able to carry a caption containing a table; captions now render with the same formatting as replies</li>
<li>[Claude Tag] Fixed Claude's threads in Slack's Agents &amp; tools view sometimes being listed under their first message instead of their name; later renames now update the list too</li>
<li>[Claude Tag] Fixed removing a GitHub organization's grant from an access bundle's Repositories tab in Claude Tag admin settings failing to save after that GitHub organization was disconnected</li>
<li>[Claude Tag] Fixed Claude always replying "Couldn't check this channel just now" in a channel shared with a Grid workspace it isn't added to; the notice now says which workspace needs the app</li>
<li>[Claude Tag] Fixed the cost and token totals in Claude's reply footer reading many times too high after the session's cloud worker restarted</li>
<li>[Claude Tag] Changed the bordered cards Claude uses in Slack replies for plans, tables and details to render wide by default instead of a narrow width</li>
<li>[Claude Tag] Changed newly connected Slack workspaces to follow the current default model instead of keeping whichever model was the default when they were connected</li>
