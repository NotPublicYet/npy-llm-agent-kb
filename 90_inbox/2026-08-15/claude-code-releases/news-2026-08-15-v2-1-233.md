## Summary
<h2>What's changed</h2>
<ul>
<li>Added GitLab merge request URL support to the <code>--worktree</code> flag and the <code>claude agents</code> view (where MRs display as <code>!N</code>)</li>
<li>Added an opt-in <code>forward_user_identity</code> apps gateway setting on Anthropic upstreams that sends the signed-in user's identity as headers, so a proxy behind the gateway can attribute spend per user</li>
<li>Added opt-in memory cgroup support for Bash tool commands on Linux (<code>CLAUDE_CODE_TOOL_MEMORY_LIMIT</code>) so a runaway build can't stall the session</li>
<li>Added <code>CLAUDE_CODE_WEBFETCH_CACHE_TTL_MS</code> environment variable to configure the WebFetch session URL cache TTL (default unchanged: 15 minutes)</li>
<li>Fixed cloud sessions occasionally being marked as lost when the environment shut down while Claude was waiting on a permission prompt</li>
<li>Fixed MCP v2 connections endlessly reopening the subscriptions/listen stream against servers that terminate long-held streams on a fixed timeout (e.g. serverless hosts)</li>
<li>Fixed Notification hooks not firing for permission prompts when running under Claude Desktop or VS Code</li>
<li>Fixed idle sessions on Linux sometimes keeping one CPU core at 100% when sandboxing is enabled</li>
<li>Fixed bundled skill aliases like <code>/checkup</code> and <code>/review</code> reporting "Unknown command" in <code>-p</code> mode or with plugins/MCP loaded when a user or project skill shadows the bundled skill</li>
<li>Fixed skill/command argument substitution to prevent argument values from being re-expanded as template markers</li>
<li>Fixed Windows paths spelled with the NT <code>\??\</code> device prefix bypassing UNC path validation, closing an NTLM credential-leak vector</li>
<li>Improved <code>claude self-hosted-runner</code> session start time: the session branch is now created without rewriting the working tree, and two server round trips no longer block the agent's launch</li>
<li>Improved apps gateway error forwarding: 400/413 errors from Vertex, Foundry, and Claude Platform on AWS upstreams now carry the upstream's own message; fixes a bug with auto-compact on apps gateway</li>
<li>Improved <code>claude plugin validate</code> to check a bare <code>.claude/skills</code> directory, reporting SKILL.md files whose frontmatter fails to parse</li>
<li>Improved screen reader mode: the <code>/effort</code> selector renders as a numbered list with a typed-number prompt, and hint and dialog text is no longer clipped</li>
<li>Improved print mode diagnostics: a <code>[claude-code:unrecognized_model]</code> line is written to stderr when a request goes out for a model ID Claude Code doesn't recognize; map it with <code>modelOverrides</code> to silence</li>
<li>Changed the GitHub app setup tip to no longer appear in repositories whose origin remote is on gitlab.com or bitbucket.org; the enterprise marketplace tip now covers non-GitHub internal git hosts</li>
<li>Todo/task-tracking tools (TaskCreate/Get/Update/List, TodoWrite) are no longer available on Opus 4.8, Sonnet 5, Fable 5, Mythos 5, and newer models; set <code>CLAUDE_CODE_ENABLE_TODO_TOOLS=1</code> to bring them back</li>
<li>Windows: fixed auto mode repeatedly stopping for manual approval on ordinary <code>cd &lt;dir&gt; &amp;&amp; &lt;command&gt; &gt; file</code> Bash commands (a 2.1.232 regression)</li>
<li>Reverted the 2.1.232 Bash permission changes for Cygwin-style symlinks on Windows and for input redirections (<code>&lt; file</code>); a narrower version will return in a later release</li>
</ul>
