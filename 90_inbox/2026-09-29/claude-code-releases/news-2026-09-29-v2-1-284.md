## Summary
<h2>What's changed</h2>
<ul>
<li>Added Claude Sonnet 5.5 (<code>claude-sonnet-5-5</code>), now the default Sonnet model on the Anthropic API — 1M context, $2/$10 per Mtok with $0.20/Mtok cache reads</li>
<li>Added a "Yes, but ask again next time" answer to auto mode's prompt before a read outside the working directories, so you can allow that one read and still be asked about later ones</li>
<li>Added dollar amounts to the Claude apps gateway spend limit in <code>/usage</code> and the status line (for example "$271.40 / $500.00 spent this month") when the gateway runs this version or later; the status line's <code>rate_limits.spend_limit</code> also gains <code>used_usd</code>, <code>limit_usd</code> and <code>period</code></li>
<li>Added <code>effortSlider:decreaseEffort</code>, <code>increaseEffort</code> and <code>toggleUltracode</code> keybinding actions, so the <code>/effort</code> slider's arrow and Tab keys can be rebound in <code>keybindings.json</code></li>
<li>Added <code>/rate-limit-options</code> to <code>/help</code> and the command menu for claude.ai subscribers, so the usage-limit notices that mention it point to a command you can find</li>
<li>Added <code>/mcp reconnect all</code> in the interactive terminal to retry every MCP server that failed to connect or needs authentication at once</li>
<li>Added Claude apps gateway startup warnings when a managed policy's <code>availableModels</code> is empty, or leaves out the model Claude Code starts on without setting <code>model</code> or <code>enforceAvailableModels</code></li>
<li>Added <code>auth: { google: {} }</code> for Claude apps gateway <code>telemetry.forward_to</code> destinations, so telemetry can be exported straight to Google Cloud's OTLP endpoint using the gateway's Google Cloud credentials</li>
<li>Added certificate client authentication (<code>private_key_jwt</code>) between the Claude apps gateway and its identity provider, for identity providers that issue certificate credentials instead of client secrets</li>
<li>Fixed a damaged response stream showing raw errors such as "JSON Parse error" or "undefined is not an object", or writing the word "undefined" into an answer, instead of being retried or reported as an interrupted response</li>
<li>Fixed an overloaded or server error arriving right after a thinking block ending the turn with an error instead of being retried</li>
<li>Fixed "Prompt is too long" errors that persisted after compacting: when the compacted request is still too long, Claude Code now compacts once more, keeping less of the recent conversation</li>
<li>Fixed a session whose model is unavailable, with no fallback model left, showing a bare "is currently unavailable" message (or "Something went wrong" in cloud sessions) instead of the model-unavailable notice and its Learn more link</li>
<li>Fixed Agent SDK sessions crashing when a user message contains an image with a malformed <code>source</code>, and failing on every later turn after a malformed document block; a malformed image is now replaced with an explanatory note</li>
<li>Fixed MCP tool calls in a resumed session failing with "No such tool available" while their server was still connecting; the call now waits up to 10 seconds for the server</li>
<li>Fixed repeated calls to the plan-usage endpoint after it rate-limits or rejects your login: <code>/usage</code>, <code>/extra-usage</code> and IDE usage views now back off instead of re-asking</li>
<li>Fixed <code>claude mcp add</code> reporting success when managed settings restrict MCP servers to plugins; it now refuses and says what to do, instead of saving a server that never loads</li>
<li>Fixed the <code>/plugin</code> configure screen: boolean options are now a true/false choice instead of free text, number options refuse invalid input, and ←/→ change an options field instead of switching tabs</li>
<li>Fixed <code>ANTHROPIC_FOUNDRY_RESOURCE</code> being interpolated into the Foundry endpoint host unvalidated; a value that is not a plain resource name is now refused</li>
<li>Fixed Claude Desktop behind a Claude apps gateway offering no 1M context option: the gateway now marks each 1M-capable model for Desktop automatically</li>
<li>Fixed ↓ in shell mode selecting a hidden background-tasks pill, which stopped Backspace and Ctrl+U from editing the prompt</li>
<li>Fixed Bash tool failing on Windows with many plugins enabled: plugin <code>bin/</code> directories that don't exist are no longer added to PATH, and inherited entries aren't added twice</li>
<li>Fixed <code>sparsePaths</code> plugin marketplaces cloning empty and replacing a working local copy on older git (before 2.39), which failed every refresh with "marketplace.json file is no longer present"</li>
<li>Fixed fullscreen rendering erasing the terminal output above the session when <code>[</code> in transcript mode writes the conversation to scrollback (macOS and Linux)</li>
<li>Fixed fullscreen scroll position jumping to the previous message or to the bottom when a reply finished streaming while scrolled up</li>
<li>Fixed tab bars in dialogs such as <code>/config</code> and <code>/plugin</code> breaking the title and tab labels mid-word in a narrow terminal; a tab that doesn't fit now moves to the next line whole</li>
<li>Fixed the <code>/model</code> picker showing "+1 model" below the list after scrolling to the last model; the count now covers only the models below the visible rows</li>
<li>Fixed <code>/keybindings</code> writing Backspace and Delete bindings for a footer action that does nothing into the generated <code>keybindings.json</code></li>
<li>Fixed a rebound agent panel close key (<code>footer:close</code>) typing "x" instead of itself on the row of the agent you're viewing</li>
<li>Fixed vim mode <code>.</code> not repeating text typed very fast (for example over ssh or in tmux) or pasted without bracketed paste, and leaving the prompt in INSERT mode after repeating a change with nothing typed (such as <code>cw</code> then Esc)</li>
<li>Fixed vim mode leaving the cursor on an image placeholder's opening bracket after <code>dd</code> on the last line or <code>yy</code> at the end of the prompt, where <code>r</code> or <code>x</code> would break or delete the image</li>
<li>Fixed a key pressed the instant the terminal regained focus answering the Remote Control enable prompt before its short safety delay restarted</li>
<li>Fixed the workspace trust dialog appearing a second time after switching renderers or updating when Claude Code was started in the home directory</li>
<li>Fixed rules symlinked into <code>.claude/rules</code> from outside the project being skipped without ever showing the external-imports approval prompt; a <code>.claude</code> directory symlinked from outside the project now asks for the same approval</li>
<li>Fixed plugins from marketplaces, claude.ai and npm pre-approving their own tools via <code>allowed-tools</code> under managed <code>allowManagedPermissionRulesOnly</code>; only plugins from an official Anthropic source or a source that managed settings vouch for keep that pre-approval</li>
<li>Fixed a failed first <code>claude plugin install</code> leaving the plugin enabled and recorded when a dependency's version range could not be met</li>
<li>Fixed the debug log dropping a failed hook's stderr when the hook also wrote to stdout, and logging nothing for a failed hook with no output; failed hooks now also log their status code</li>
<li>Fixed <code>{"decision":"block"}</code> returned by Elicitation and ElicitationResult hooks being ignored; it now declines the MCP elicitation, as exit code 2 does</li>
<li>Fixed sessions launched without the <code>SendMessage</code> tool (such as by Claude Desktop) still being told to message other sessions with it</li>
<li>Fixed a photo sent from the Claude app over Remote Control being lost when its queued message was pulled back into the terminal prompt to edit, and the cursor moving one character for a photo with no caption</li>
<li>Fixed typing a message during an automatic usage-limit wait taking the wait out of the "Continue automatically at usage limit" setting's control when that turn hit the limit again</li>
<li>Fixed usage-limit warnings suggesting <code>/upgrade</code> to users already on the highest Max plan; the warnings and <code>/upgrade</code> itself now point at <code>/usage-credits</code> when it is available</li>
<li>Fixed the Explore subagent switching to Opus on the Claude API when the session runs a model ID Claude Code doesn't recognize, such as a custom model behind a proxy; Explore now inherits that model</li>
<li>Fixed <code>/loop</code> status updates in self-paced mode often not being shown because Claude wrote them only in its reasoning; Claude now writes each update, and the outcome when the loop stops, as visible text</li>
<li>Fixed <code>/ultrareview</code> failing to upload the working tree when started from a git worktree that the Claude desktop app created on macOS or Linux</li>
<li>Fixed sandboxed Bash commands failing to start on Linux when the working directory is write-denied and contains a read-denied directory</li>
<li>Fixed artifact database write results telling Claude that every viewer sees a write to a viewer's private <code>data/users/</code> subtree, and added a "view" level to <code>as_level</code></li>
<li>Fixed the Claude apps gateway answering <code>431 Request Header Fields Too Large</code> to every request from a sign-in whose identity provider lists many groups; it now accepts request headers up to 256 KiB</li>
<li>Improved the usage-limit wait: the limit's state and the countdown with the usage-credits option now show as one block under the prompt, and limit messages no longer repeat the countdown</li>
<li>Improved the "No such tool available" error for Claude in Chrome tools called without their prefix: it now names the tool to call</li>
<li>Improved Monitor event rows to show what each event printed instead of repeating the description, and stopped repeating an unchanged "Waiting for N … to finish" line after every event</li>
<li>Improved Workflow tool sandbox hardening for errors thrown by async script hooks</li>
<li>Improved startup time and memory use by building only the parts of the settings schema that your settings files actually use</li>
<li>Improved <code>/claude-api</code>: <code>hillclimb</code> no longer spends rounds on prompt rewordings too small for the eval to measure, and an extra page you ask for beside <code>report.html</code> is built as one local file that loads nothing from the network</li>
<li>Improved lists such as <code>/tasks</code>, <code>/copy</code> and <code>/hooks</code>: the details after each name now line up in one column when they fit, and otherwise sit at the right edge</li>
<li>Improved <code>claude plugin marketplace add</code> to say when it replaces a marketplace already added under the same name from a different source, and how to undo it</li>
<li>Improved the startup refusal when managed settings require a sign-in (<code>forceLoginMethod</code> or <code>forceLoginOrgUUID</code>) and an API key, token or <code>apiKeyHelper</code> is configured: it now names the credential in use, where it is set, and how to remove it</li>
<li>Improved auto-memory loading: invisible characters and tags that imitate Claude Code's own markup are neutralized in <code>MEMORY.md</code> and recalled memory notes before they reach Claude</li>
<li>Improved <code>claude remote-control</code>: in a folder you haven't trusted yet, it now asks for workspace trust on the terminal instead of exiting</li>
<li>Improved artifact pages: Claude writes its design plan into the page instead of the reply, and uses the name you already gave something as the page title</li>
