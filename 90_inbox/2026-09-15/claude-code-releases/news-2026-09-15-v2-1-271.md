## Summary
<h2>What's changed</h2>
<ul>
<li>Added fast mode in Claude Code Remote sessions (cloud and self-hosted runners): the host's fast-mode setting or <code>/fast</code> typed in the session applies where your organization allows it</li>
<li>Added mouse support to the <code>/config</code> panel in fullscreen mode: the wheel scrolls the settings list, a click on a setting's value changes it, and the row under the pointer is highlighted</li>
<li>Added <code>claude self-hosted-runner --drain-marker-file &lt;path&gt;</code>: when that file exists at a SIGTERM drain, the runner reports its exit to the server as a host drain (telemetry only)</li>
<li>Added per-command <code>allowed_domains</code> to Bash, PowerShell and Monitor in auto mode with sandboxing: the hosts a command needs are reviewed with it and opened for it alone; other hosts are refused</li>
<li>Added <code>omitClaudeMd</code> to agent frontmatter and <code>--agents</code> JSON, letting custom and plugin subagents run without user, project and local CLAUDE.md files; managed policy files still load</li>
<li>Added <code>--accept-command &lt;sha256&gt;</code> to <code>claude plugin install</code> and <code>claude plugin update</code> to accept exactly the command a previous <code>--json</code> run displayed, instead of <code>-y</code></li>
<li>Added support for a <code>multiplier</code> above 1, up to 10, in the <code>modelPricing</code> managed setting and the Claude apps gateway <code>pricing</code> block, for marked-up internal chargeback rates</li>
<li>Added a spinner tip pointing Bedrock, Vertex AI, Foundry and LLM gateway users to the Claude desktop app; the claude.ai desktop app tip now suggests <code>/desktop</code>, which offers to download the app</li>
<li>Fixed a cached organization policy being reused after switching accounts, organizations, or API keys, and the policy not refreshing until the hourly check when the credential changes mid-session</li>
<li>Fixed the tool and command lists not updating when the organization policy finishes loading after startup or changes mid-session</li>
<li>Fixed an enterprise <code>managed-mcp.json</code> that can't be read or parsed being ignored: it now keeps exclusive MCP control (user, project and plugin servers don't load) and warns at startup</li>
<li>Fixed org policy being fetched through, and rejected by, third-party local proxies set via <code>ANTHROPIC_UNIX_SOCKET</code>; they are again treated like other custom gateways, including for Remote Control</li>
<li>Fixed cloud sessions rejecting every subagent tool call ("updatedInput … failed schema validation") when a workflow or agent approval was applied after the session's worker restarted</li>
<li>Fixed <code>/fast off</code> answering "Fast mode unavailable" instead of turning fast mode off when the organization has fast mode disabled</li>
<li>Fixed sessions started with <code>CLAUDE_CODE_SKIP_FAST_MODE_ORG_CHECK</code> re-sending fast requests every turn after the API rejected fast mode; the rejection now stands and its reason is shown</li>
<li>Fixed fast mode under <code>CLAUDE_CODE_RETRY_WATCHDOG</code> failing the turn on a usage-credits limit, or retrying an overload at fast speed, instead of falling back to standard speed</li>
<li>Fixed Bash permission checks missing the file that <code>fmt</code>, <code>column</code> and similar commands read when it follows an option the checker doesn't recognize</li>
<li>Fixed Bash permission checks skipping files a wildcard expands to when the wildcard sits in a command's pattern or option value (for example <code>grep -v dir/* file</code>)</li>
<li>Fixed Bash permission checks so that shell variable declaration flags cannot misrepresent the command being run</li>
<li>Fixed Bash commands with two directory changes, a subshell, or a <code>cd</code>+<code>git</code> chain skipping the prompt under <code>permissions.blockReadsOutsideWorkingDirectories</code> in bypass and auto mode</li>
<li>Fixed a stale <code>.git/config.lock</code> breaking <code>git checkout -b</code>, <code>git push -u</code> and <code>git config</code> for the rest of a session after a sandboxed command failed to start (Linux)</li>
<li>Fixed settings file changes made outside the session going unnoticed on macOS machines whose system file-event service is saturated; the watcher now falls back to polling</li>
<li>Fixed resumed <code>claude -p</code> sessions whose tools all come from MCP servers failing with "At least one tool must have defer_loading=false"</li>
<li>Fixed turns failing with "API returned an empty or malformed response" when an LLM gateway returns the non-streaming reply as <code>text/plain</code></li>
<li>Fixed sustained high CPU usage and repeated tool-list requests when an MCP server sends <code>list_changed</code> notifications in a tight loop</li>
<li>Fixed MCP OAuth mishandling client registrations: denying consent forced a new one, one for another redirect URI was reused, and a concurrent write could delete a valid one or keep a mismatched one</li>
<li>Fixed tool search returning no match when Claude selects an MCP tool by its bare name instead of its full <code>mcp__server__tool</code> name</li>
<li>Fixed Ctrl+O cancelling pending MCP server reconnects, and <code>/mcp</code> sent from Remote Control failing while the transcript view is open</li>
<li>Fixed the Claude in Chrome prompt telling the model to load tools through ToolSearch when ToolSearch is unavailable</li>
<li>Fixed cross-session messages held by the receiving session's permission-mode policy leaving no trace: headless senders now get a delivery notice, and <code>SendMessage</code> results no longer imply it was read</li>
<li>Fixed Claude starting a second copy of a background command (such as a watch task or dev server) that was still running after the conversation was compacted</li>
<li>Fixed <code>/model</code> warning about losing the conversation cache when switching back to the model the conversation actually ran on</li>
<li>Fixed <code>/reload-skills</code> reporting a skill count that disagreed with the slash menu after <code>/cd</code></li>
<li>Fixed <code>/resume</code> and <code>/continue</code> showing only 1-2 sessions in fullscreen mode on short terminals</li>
<li>Fixed <code>/resume</code> and <code>/teleport</code> keeping the previous conversation's file-read tracking, so Claude could edit files the resumed conversation had never read</li>
<li>Fixed <code>--resume</code> dropping the 1M context window (<code>[1m]</code>) when the resumed session's model family differs from the configured default model</li>
<li>Fixed artifacts attached with <code>/artifacts</code> disappearing from the session after <code>--resume</code></li>
<li>Fixed background sessions (<code>claude --bg</code>, <code>claude agents</code>) not watching the artifacts they publish for republishes made elsewhere</li>
<li>Fixed custom agents, slash commands and output styles beyond the first not loading from a virtual drive that reports inode 0, such as an encrypted vault mounted as a Windows drive</li>
<li>Fixed self-hosted runner sessions silently losing all host config (settings, skills, plugins, MCP servers) when the host config directory exceeds 64 MiB; added <code>--host-config-snapshot disk|memory</code></li>
<li>Fixed skills synced from claude.ai staying on disk indefinitely after signing out; copies not refreshed within <code>cleanupPeriodDays</code> now move to the recoverable trash at the next launch</li>
<li>Fixed spinner tips suggesting commands that aren't available for your account type or are disabled in your session</li>
<li>Fixed the <code>/add-dir</code> path input: the left and right arrow keys now move the cursor, and Enter adds only the typed path instead of also adding the highlighted completion</li>
<li>Fixed text fields outside the main prompt moving a leading <code>!</code> to the end of what you typed (<code>!foo</code> came out as <code>foo!</code>)</li>
<li>Fixed the interactive <code>/hooks</code> menu crashing when a hook matcher is named after an inherited object property such as <code>__proto__</code> or <code>constructor</code></li>
<li>Fixed a fullscreen rendering glitch where text kept a stale background color after the box around it lost its background</li>
<li>Fixed Delete in st and Alt+arrow keys in rxvt-unicode not working in attached background sessions</li>
<li>Fixed the terminal's replies to capability queries (<code>^[[?1;2c</code>) appearing at the shell prompt or in an editor when Claude Code exits, is suspended, or opens an editor right after starting</li>
<li>Improved terminal rendering performance: large diffs and long transcripts render faster, with fewer slow frames</li>
<li>Improved startup time slightly by skipping a redundant validation of built-in model data on every launch</li>
<li>Improved hook feedback: while a SessionStart, UserPromptSubmit, PreToolUse or SessionEnd hook runs, the spinner says so with elapsed time, and Esc cancels a prompt waiting on a SessionStart hook</li>
<li>Improved the spinner status during long thinking: it now reads "deep in thought" after 45s, and shows "picking the thought back up" while recovering from the output-token limit</li>
<li>Improved dynamic workflows to pause when you hit your usage limit and continue automatically when it resets, instead of dropping the affected agents</li>
<li>Improved Remote Control to leave fewer empty sessions on claude.ai when setup fails on a flaky network</li>
<li>Improved the Claude in Chrome message in cloud sessions when the browser can't be reached: it now says the computer may be asleep before it suggests an install</li>
<li>Improved <code>claude mcp serve</code>: a running tool call now sends a progress update every 30 seconds, so clients show it is still running and idle timeouts don't abort a long command that prints nothing</li>
<li>Improved Foundry and Claude Platform on AWS sessions: an <code>alwaysLoad</code> MCP server that finishes connecting mid-conversation is usable on the next turn without a tool-search round trip</li>
<li>Improved Markdown files published as artifacts: they now render as styled document pages (title header, document typography, syntax-highlighted code)</li>
<li>Improved Artifact tool publish errors: a publish with no file now says to write the page to a file first, and an unsupported file type is reported before a missing favicon</li>
<li>Improved the Artifact tool's error when a page declares a capability its contract version lacks: it now lists every supported capability and notes when a newer contract version has it</li>
<li>Improved artifact watching: a session can now watch up to 10 published artifacts at once for republishes made elsewhere, up from 5</li>
<li>Improved PDF @-mentions to say "page count unknown" instead of a page count guessed from the file size when pdfinfo cannot count the pages</li>
<li>Improved <code>/mobile</code> to show a single QR code for claude.ai/mobile, which opens the right app store for your phone</li>
<li>Changed auto mode so that a skill's or slash command's inline <code>!</code> shell commands follow default-mode permission rules instead of the classifier; a command no rule decides runs as a reviewed tool call</li>
<li>Changed auto mode so a subagent reports back to its caller through a dedicated hand-back call that the safety classifier reviews, instead of its last message being reviewed after the fact</li>
<li>Changed Monitor watches to always have a deadline (at most 30 minutes; 10 in single-prompt <code>-p</code> runs) and notify Claude to re-arm, replacing the no-timeout <code>persistent</code> option</li>
<li>Changed the IDE selection indicator in the prompt to a <code>[⧉ …]</code> pill that wraps with the text instead of squeezing multi-line prompts; delete it with Backspace to leave the selection out</li>
<li>Changed the default dynamic workflow size to small on Pro plans and lowered the medium size guideline from 15 to 10 agents</li>
<li>Changed Claude apps gateway, Bedrock, Vertex AI, and Foundry sessions so that they no longer refresh a leftover claude.ai login that the session does not use</li>
<li>Updated the bundled <code>claude-api</code> skill to enable <code>eager_input_streaming</code> on streaming custom tools, and to start deliverable-shaped Managed Agents work with <code>user.define_outcome</code></li>
<li>[VSCode] Added an Attach Open File setting that, when turned off, stops the open file from being added to messages; selected text is still attached</li>
<li>[VSCode] Fixed the Hooks and Permission rules dialogs reporting a save that landed as failed, and the Hooks dialog going blank under a plugin-only policy lock or showing color codes in save errors</li>
<li>[VSCode] Fixed Hooks dialog saves: no duplicate hook on replace, a header name retyped in other capitals keeps its secret, and settings.local.json is gitignored before the save returns</li>
<li>[VSCode] Fixed session history showing only the current session when the workspace is on a Windows mapped network drive or SUBST drive</li>
<li>[VSCode] Fixed the session list's Active filter hiding open idle sessions when Open is also checked in the filter menu</li>
<li>[VSCode] Fixed a new chat switching back to the previous chat when the session list refreshed</li>
<li>[VSCode] Fixed open tabs and the side bar keeping the old config folder until a window reload after <code>CLAUDE_CONFIG_DIR</code> changed in the <code>environmentVariables</code> setting</li>
<li>[VSCode] Fixed console windows flashing on Windows when the extension runs background commands such as git, ripgrep, and the sign-in status check</li>
<li>[VSCode] Fixed the prompt cache clock's hover text appearing only after a delay, and the auto-compact icon showing the browser's own tooltip beside its popup</li>
<li>[VSCode] Improved the Hooks dialog: a save refused because of the settings file itself now opens a popup with an "Open settings file" button and the reason behind "Copy error"</li>
<li>[VSCode] Changed the on state of toggle switches from Claude orange to the editor theme's button color</li>
<li>[Claude Code on the web] Fixed a cloud session sometimes taking about ten minutes to respond after its process exited while the session still looked live; sending a message now restarts it right away</li>
<li>[Claude Code on the web] Changed the Routines page on claude.ai/code to a new layout with Yours and Templates tabs and two-column routine cards that show run status, and removed its calendar view</li>
<li>[Claude Code on the web] Added a Custom network access option to the Cloud environments editor in admin settings, with the same allowed-domains list the environment dialog on claude.ai/code offers</li>
<li>[Claude Code on the web] Improved the Cloud environments admin page: it shows the default environment for Claude Tag and Claude Code, with a link to change it, and marks the recommended kind to create</li>
<li>[Claude Tag] Fixed Claude in a channel where it stays active losing its working context about once an hour when the conversation is mostly in threads; thread activity now keeps it from being reset</li>
<li>[Claude Tag] Fixed a thread that asked Claude to watch a pull request no longer hearing about CI failures, comments and reviews after Claude was restarted in that thread</li>
<li>[Claude Tag] Fixed deleting the first message of a thread Claude had already replied in not ending Claude's work there; it now stops, as it did when a message with no replies was deleted</li>
<li>[Claude Tag] Fixed Claude holding back a post because of an earlier instruction addressed to a different bot or assistant; only instructions addressed to Claude bind it, and it asks when unsure</li>

<li>[Code Review] Fixed Code Review occasionally posting the same findings two or three times when GitHub reported an error for a review it had in fact created</li>
<li>[Code Review] Fixed follow-up reviews re-posting a security finding a person had already resolved when a later push moved the lines it was anchored to</li>
<li>[Code Review] Fixed reopening a finished /ultrareview cloud session in the Claude app starting the whole review over again unprompted</li>
<li>Windows: Fixed PowerShell commands failing with "Exit code 1" and no output when the session's temp output path reaches 260 characters</li>
