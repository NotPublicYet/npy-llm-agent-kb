## Summary
<h2>What's changed</h2>
<ul>
<li>Added Claude Fable 5.2 (<code>claude-fable-5-2</code>), now the default Fable model — 1M context, $8/$40 per Mtok with $0.20/Mtok cache reads</li>
<li>Added <code>--settings &lt;file&gt;</code> to <code>claude remote-control</code>, which applies a settings file to every session it starts; if the file changes, no new session starts until you restart <code>claude remote-control</code></li>
<li>Fixed MCP OAuth requests sending secrets such as refresh tokens to another host when a server redirected them</li>
<li>Fixed a case where a read-only Bash command ran outside the sandbox without a permission prompt</li>
<li>Fixed a case where Bash permission checks judged a file write from the wrong folder and didn't prompt</li>
<li>Fixed deny rules and protected-file prompts not applying to the file that a <code>cp</code> or <code>mv</code> into a directory writes</li>
<li>Fixed the "Draws from usage credits" note showing after a switch to Fable on Enterprise seats whose plan includes Fable</li>
<li>Fixed the fallback model sometimes declining a request or mentioning a stopped response when the first model was blocked before replying</li>
<li>Fixed <code>claude mcp login</code> printing a SEP-2352 issuer warning each time you sign in again to a server that Claude Code registered with</li>
<li>Fixed <code>NotebookEdit</code> deleting or overwriting a notebook's first cell when the call named no cell, on network paths (UNC shares, WSL folders, <code>/net</code> mounts)</li>
<li>Fixed Edit changing the first of several matches, replacing a whole file on an empty <code>old_string</code>, or editing a notebook as text, on network paths (UNC shares, WSL folders, <code>/net</code> mounts)</li>
<li>Fixed <code>/config</code> showing Manual as the default permission mode when new sessions start in auto mode; pressing Space on "Auto (default)" now saves Don't Ask, not Plan</li>
<li>Windows: Fixed <code>FileChanged</code> hooks stopping for paths set through <code>watchPaths</code> after the first shell command, when the session's working directory had a lowercase drive letter</li>
<li>Fixed <code>--plugin-dir .</code> and <code>--plugin-dir ./builtin</code> writing generated type files for Claude Code's built-in plugins into a <code>builtin</code> folder</li>
<li>Fixed context usage estimates overcounting tool definitions when exact token counts are unavailable</li>
<li>Fixed <code>/compact</code> showing twice in Remote Control on web and mobile</li>
<li>Fixed plugin auto-updates and <code>/plugin</code> marketplace updates downloading a plugin again for each worktree or folder of a repository</li>
<li>Fixed auto mode losing a background subagent's report that had started a turn when the conversation was compacted before Claude answered it</li>
<li>Fixed project skills, commands and agents staying missing after their folder was removed and came back mid-session, such as with <code>git stash</code>, including after entering a worktree</li>
<li>Fixed <code>claude -p</code> sometimes telling Claude that background commands get 30 minutes when they are stopped after 10</li>
<li>Fixed <code>pkill</code>, <code>pgrep</code> and <code>pidwait</code> in cloud sessions matching the session's own parent processes</li>
<li>Fixed Claude in Chrome and computer use server processes staying alive after their parent exits behind a proxy that stalls connections</li>
<li>Fixed a large hook output pointing Claude to a file that held another hook's output from the same tool call</li>
<li>Fixed apps that embed Claude Code getting their own PreToolUse hook's <code>ask</code> reason instead of another hook's when both asked</li>
<li>Fixed a PreToolUse hook's <code>ask</code> being lost when another hook's <code>defer</code> finished first and could not be honored</li>
<li>Fixed a rare crash on permission prompts and background tasks</li>
<li>Fixed project skills, commands and agents disappearing from the menu in SDK and desktop sessions after Claude entered a worktree</li>
<li>Fixed <code>/desktop</code> on macOS saying Claude Desktop is not installed when it is in <code>~/Applications</code></li>
<li>Fixed OpenTelemetry repository attributes (<code>vcs.*</code>) missing from Claude Desktop sessions that start on a pre-started process</li>
<li>Fixed WebFetch passing "No response from model" to Claude as page content when the model reading the page returned no text; the call now fails with a clear error</li>
<li>Fixed screen reader mode delaying the prompt at startup when the system clock moved back while Claude Code was starting</li>
<li>Fixed a command's panel sometimes not coming back after a dialog closed, leaving no panel or prompt on screen until the next redraw</li>
<li>Fixed a project's MCP server being disconnected after the first message in a Claude Desktop Code tab session when the desktop app has an MCP server or extension of the same name</li>
<li>Fixed a turn ending with "API Error: EPROTO: The TLS handshake failed" when the connection broke partway through a reply; the partial reply is kept or the request is retried, as before 2.1.302</li>
<li>Fixed high memory use in long sessions that repeatedly read single lines from large files</li>
<li>Fixed fast mode losing replies, switching models or retrying for minutes when fast serving is rate-limited, overloaded or failing; it now tries standard speed on the same model first</li>
<li>Fixed one request carrying far more background agent reports than intended after Claude was stopped while several were waiting</li>
<li>Fixed messages from a Claude Desktop Code tab session to your other sessions staying paused after you typed while Claude was still working</li>
<li>Fixed <code>claude agents</code> ignoring <code>--permission-mode</code>, <code>--dangerously-skip-permissions</code>, <code>--model</code>, <code>--effort</code> or <code>--agent</code> typed before <code>agents</code> when a flag such as <code>--verbose</code> was also on the line</li>
<li>Fixed a case where Remote Control showed as off with "login expired" in the desktop app while its connection was still up, because the app was briefly unable to hand over a sign-in token</li>
<li>Fixed a Remote Control message sent with "Queue for later" reaching Claude in the middle of the running turn</li>
<li>Fixed the git status given to Claude at session start reading as clean when git status failed; it now reads as unavailable</li>
<li>Fixed the git status given to Claude at session start showing the first listed file as staged when its changes were not staged</li>
<li>Fixed a hang or out-of-memory crash when a connector in a cloud session lists resources with very long names</li>
<li>Fixed Remote Control showing as connected after its connection closed for good while the session's history was still uploading</li>
<li>Fixed screen reader mode turning off when you return to a conversation from agent view</li>
<li>Fixed screen reader mode y/n questions taking as yes a stray "y" at the end of text typed as the question opened</li>
<li>Fixed cloud sessions telling Claude that a host is probably not allowed when it is allowed and the network proxy could not connect to it</li>
<li>Fixed an MCP server sometimes showing as connected with no tools after it was reconnected or the session's directory changed while its tools were still loading</li>
<li>Fixed Bash commands sometimes running in the wrong folder when Claude sent several at once and an earlier one changed folders</li>
<li>Fixed files Claude sends from cloud and Remote Control sessions failing at once when an upload gets an HTTP 507 from a proxy; the upload now gets a second try</li>
<li>Fixed new messages not being saved, and <code>claude -p</code>, SDK and VS Code sessions hanging, when memory ran out while the transcript was being read</li>
<li>Fixed sign-in, token refresh and logout waiting indefinitely when something on the network accepts the connection but never answers the TLS handshake</li>
<li>Fixed a sent file showing under a different name in the Claude apps when its name hid text-direction or control characters; Claude now refuses to send such a file</li>
<li>Fixed sub-agent progress summaries running a request to its end after the model replied with a tool call</li>
<li>Fixed Bash reads such as <code>grep -r foo "$PWD/src"</code> asking for permission when the same command with the path typed out runs without asking</li>
<li>Fixed Claude apps gateway refusing to start when a <code>desktop</code> setting holds a field newer than the gateway, such as a managed MCP server's <code>oauth.omitResource</code>; it now warns and serves it</li>
<li>Fixed Bash commands coming back empty for zsh users whose <code>.zshrc</code> sets <code>KSH_OPTION_PRINT</code></li>
<li>macOS: Fixed "Unable to read managed policy settings" at startup when a valid MDM profile was slow to read: the read is retried once, and a timeout is now reported as a timeout</li>
<li>Fixed agent view erasing another agent view's saved input text when it restarted for an update with nothing typed</li>
<li>Fixed remote sessions giving no reply after a restart when a <code>UserPromptSubmit</code> hook blocked a replayed permission answer; these hooks no longer run on that replay</li>
<li>Fixed <code>claude remote-control</code> accepting a <code>y</code> typed without Enter at its first-run question when the terminal's input ended</li>
<li>Fixed Claude Desktop not showing spend limit warnings behind a Claude apps gateway whose policy has no <code>code:</code> rules</li>
<li>Fixed fullscreen sessions with some plugins ending with an error when a tool result that had got shorter scrolled off the top of the screen</li>
<li>Fixed prompt suggestions making extra API requests when the model replied with a tool call</li>
<li>Fixed <code>PreToolUse</code> <code>mcp_tool</code> hooks on stdio and HTTP MCP servers being skipped when their answer was over 16 MiB; the tool call is now refused</li>
<li>Fixed skill and command names holding a Bamum letter that some fonts draw as blank: they are now refused</li>
<li>Fixed <code>claude -p</code> on Linux exiting 0 in silence when a full NFS export or a used-up NFS quota lost transcript lines: it now prints an error and, in text and json output, exits 1</li>
<li>Fixed background agents being reported as stopped by the user, and refused a resume, when a service interrupted a cloud session and nobody pressed Stop</li>
<li>Fixed NotebookEdit reporting success to hooks and telemetry when the edit failed, for example when the notebook changed while the permission prompt was open</li>
<li>Fixed a blank screen or no answer at startup, and empty <code>claude mcp list</code> output, when a stored MCP sign-in record was null</li>
<li>Fixed the Artifact tool telling Claude to add filters when an artifact's database collection is too large to sort; it now says to read the collection page by page and sort the results</li>
<li>Fixed a restarted cloud session dropping a message with a large image when the restart came before Claude's first reply to it</li>
<li>Fixed a restarted cloud session leaving a subagent's message to the main conversation unanswered</li>
<li>Fixed Claude not being told when you stop or pause a running workflow, so it no longer says the workflow is still running</li>
<li>Improved the <code>/model</code> picker: "More models" is now an unnumbered row below every other, and older models open under it without renumbering the rest</li>
<li>Gateway: Improved spend limits on a busy replica, which now skips fewer checks and records spend sooner</li>
<li>Improved the Claude apps gateway's sign-in limit messages in Claude Code and on the <code>/device</code> page: they no longer name gateway settings, which the gateway's own log still names</li>
<li>Improved <code>claude install</code> and the install scripts: they finish 2 to 4 seconds sooner</li>
<li>Improved how soon a Remote Control session whose process crashed can pick up a new message</li>
<li>Windows: Improved startup and first-command time by finding programs on PATH without starting a helper process</li>
<li>Improved auto mode in headless sessions, the desktop app and VS Code: reports from background subagents that wait together are answered in one model call, as in the terminal</li>
<li>Improved the agent view's row for a <code>claude --bg --worktree</code> session that couldn't set up its worktree: it now shows the error from its beginning, not an internal tag or its last 200 characters</li>
<li>Improved the messages shown when an artifact is in another organization: <code>/login</code> is offered only if it's one of yours, and Claude now says where a copy may be after an account move</li>
<li>Improved sessions with more images than fit in one request: Claude is told whether it has already seen a dropped image, and repeat reads of an unchanged image are limited</li>
<li>Improved <code>claude remote-control</code>'s messages for an unanswered first-run question: each now says what to do next</li>
<li>Improved start-up time by loading trusted TLS certificates faster</li>
<li>Improved Claude apps gateway error messages to show the gateway's address without any user name or password</li>
<li>Improved the Claude apps gateway's spend limit error: the reset now shows in your local time, such as "resets 4pm (America/Los_Angeles)"</li>
<li>Windows: Improved startup time with a standard Git for Windows install by no longer checking which git.exe to run on every launch</li>
<li>Updated the session-feedback message and the <code>allowedProviders</code> setting description to name Ultra alongside Pro and Max, and the <code>forceLoginMethod</code> description to cover every paid Claude plan</li>
<li>Updated the bundled dataviz skill to suggest a list of meters, one row per item, for several ratios that each have their own limit</li>
<li>Updated the "Upgrade to Max" options to say "Upgrade to Max or Ultra"</li>
<li>Changed mods Claude writes to turn on without asking in auto and bypass modes, even with managed <code>allowUnsandboxedCommands: false</code> or <code>allowManagedDomainsOnly</code>, and not to load in <code>dontAsk</code> mode</li>
<li>Changed mods' own tool calls (<code>$.tool.call</code>, <code>$.mcp.call</code>) to raise no permission prompt, even under your own ask rules or in <code>dontAsk</code> and <code>-p</code> runs; deny rules and organization policy still apply</li>
<li>Changed saved Fable 5.1 model picks to move to <code>fable</code>: on Pro and Max plans at once, on Team and Enterprise plans once your organization allows it; use <code>/model claude-fable-5-1</code> to switch back</li>
<li>Changed the fast mode labels in <code>/fast</code>, <code>/config</code> and <code>/model</code> to name your current model when it supports fast mode, and removed "(Opus only)" from the VS Code row</li>
<li>Changed nested skill loading: <code>.claude/skills</code> folders inside <code>~/.claude/plugins</code> no longer load when Claude works on files there</li>
<li>Self-hosted runner: Changed an on-demand runner that the server refuses because it is not needed (session ended or paused, work order superseded) to exit 0 instead of 1</li>
<li>Windows: Changed how Claude Code finds programs it starts itself, such as git, to skip relative and UNC PATH entries and links onto a network share, and to pick up PATH changes from settings</li>
<li>Changed OpenTelemetry hook events in non-interactive sessions to leave two built-in hooks out of <code>num_hooks</code> and <code>num_success</code> after Bash and PowerShell calls</li>
<li>Changed the number of messages a Claude Desktop Code tab session can send to your other sessions before it waits for you to type again from 10 to 20</li>
<li>Changed <code>AskUserQuestion</code> in <code>claude -p</code> and SDK sessions to deny a host's permission answer that sets the undocumented <code>afkTimeoutMs</code> input field</li>
<li>Changed managed <code>extraKnownMarketplaces</code>: a declared name can't be added from another source, an entry from elsewhere is hidden, and plugins the declared marketplace lists are reinstalled from it</li>
<li>Changed Claude in Chrome tools that an app running Claude Code provides, such as the Claude desktop app's Code tab, to follow your organization's Claude in Chrome policy</li>
<li>Changed <code>policy_mode: layered</code> in the Claude apps gateway: managed MCP servers now add up over every matching policy, <code>match: {}</code> included, so a gateway already on it serves more after the upgrade</li>
<li>Gateway: Changed Bedrock, Vertex and Foundry upstreams to ignore the <code>ANTHROPIC_*_BASE_URL</code> variables in the gateway's environment. Set <code>base_url</code> on the upstream to use another endpoint</li>
<li>Changed headless sessions to reload mods in <code>.claude/skills</code> when their files change; set <code>CLAUDE_CODE_PLUGIN_DIR_WATCH=0</code> to turn this off</li>
<li>Changed the Cyber Verification Program sentence on a cyber safeguard block to use the same words as claude.ai</li>
<li>Changed Cowork cloud sessions: a PostToolUse hook can no longer replace the answer to AskUserQuestion or the plan in ExitPlanMode's result; Claude reads the originals</li>
<li>Changed <code>cp</code> and <code>mv</code> spelled by a path, such as <code>/bin/cp</code>, to get the same path checks as <code>cp</code> and <code>mv</code></li>
<li>Changed background command notifications and TaskStop results to show Claude only the start and end of a command over 1,000 characters, which saves context</li>
<li>Changed artifact design guidance to treat Inter and Space Grotesk as good default typefaces</li>
<li>Changed the account email check to refuse only a shell command that holds your email and names a User-Agent, without asking, so other commands and scheduled runs no longer stop at its prompt</li>
<li>Changed Remote Control sessions to keep the folder they were started in: a connected client can no longer move a session to another folder</li>
<li>Changed managed <code>extraKnownMarketplaces</code> take-overs from an undeclared source: saved data is set aside for <code>cleanupPeriodDays</code>, and options and secrets until <code>claude plugin restore-set-aside</code></li>
<li>[VSCode] Added a warning above the prompt box when both an auth token and an API key are set, matching the terminal's startup warning</li>
<li>[VSCode] Fixed a plugin's permission request showing a name with hidden characters: it now reads "a plugin"</li>
