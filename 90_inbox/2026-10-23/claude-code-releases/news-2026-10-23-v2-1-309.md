## Summary
<h2>What's changed</h2>
<ul>
<li>Fixed sandboxed Bash commands on macOS and Linux running the shell's startup files outside the sandbox before each command</li>
<li>Fixed macOS sandbox <code>denyWrite</code> glob patterns not applying at a path's real location when the pattern's folder is reached through a symlink</li>
<li>Fixed sandboxed commands and auto-accepted edits being able to modify the MCP config file passed with <code>--mcp-config</code></li>
<li>Fixed a disabled MCP server being reconnected by a later permission prompt in print and SDK sessions</li>
<li>Fixed the Bash permission check trusting a variable set by a command whose redirect can fail to open</li>
<li>Fixed Bash permission checks not prompting for some compound commands that change directory before running git when the <code>cd</code> is wrapped or prefixed, as they do for a plain <code>cd</code></li>
<li>Fixed an <code>Edit(path)</code> deny rule not blocking a Bash redirect to that path in some commands that also held a subshell</li>
<li>Fixed worktree-isolated sessions accepting some locale-prefixed commands the isolation guard should refuse</li>
<li>Fixed worktree-isolated sessions on zsh accepting some arithmetic commands that the isolation guard should refuse</li>
<li>Fixed worktrees and branch checkouts that Claude Code creates so they ignore git replace refs, as its other git operations already do</li>
<li>Fixed profile store write protection not applying when the config directory is reached through a symlink</li>
<li>Fixed sessions compacting repeatedly after reading files under a very large nested CLAUDE.md; a nested CLAUDE.md over the size limit now loads only its start</li>
<li>Fixed ctrl+enter (send now) only queuing a message when pressed before the response had started, and restarting a prompt's hooks while leaving the message queued when pressed while those hooks were running</li>
<li>Fixed key-bound slash commands running in the shell from <code>!</code> mode</li>
<li>Fixed ctrl+o not showing messages from other agents and sessions that are still waiting to be delivered; they now appear in full under the transcript, marked as waiting</li>
<li>Fixed long tool output previews being cut through an emoji, leaving session transcripts that <code>jq</code> could not parse</li>
<li>Fixed Read reporting "File does not exist" for PDF page ranges in Linux sandboxes that share the parent's <code>/proc</code></li>
<li>Fixed messages from a Claude Desktop-hosted session sometimes being lost when its connection refreshed</li>
<li>Fixed features missing from Claude Code sessions in the Claude desktop app when the terminal on the same computer was signed in to a different account or organization</li>
<li>Fixed the <code>claude remote-control</code> status line showing <code>HEAD</code> as the branch for a folder that is not in a git repository</li>
<li>Fixed split-pane agent teammates not inheriting the tool deny and <code>--tools</code> rules given on the leader's command line</li>
<li>Fixed sessions renamed with <code>/rename</code> appearing to other sessions under a generated name after a VS Code window reload or a non-interactive <code>--resume</code></li>
<li>Fixed the <code>/rewind</code> list showing "No code changes" for a turn that changed checkpointed files through <code>/code-review --fix</code>, a subagent or a shell command</li>
<li>Fixed <code>/privacy-settings</code> showing an out-of-date "Help improve our AI models" value; it now also says when the setting can't be fetched</li>
<li>Fixed feedback saying "try again later" when your organization does not accept feedback; it now shows the server's reason and where to report a bug</li>
<li>Fixed oversized /feedback reports failing instead of being resent without the transcript</li>
<li>Fixed a skill in an <code>--add-dir</code> folder being unreachable when another skill already held its name; it is now offered as <code>&lt;folder&gt;:&lt;name&gt;</code></li>
<li>Fixed <code>/verify</code> and <code>/code-review</code> not finding a nested package's own skill when its files were changed from the shell</li>
<li>Fixed the /claude-api skill saying that <code>ant beta:worker poll --on-work</code> passes trace context to the command</li>
<li>Fixed the /claude-api skill's C# tracing setup missing spans from the cloud platform clients</li>
<li>Fixed the /claude-api skill saying that API spans for requests to Claude Platform on AWS can't join the caller's trace</li>
<li>Fixed hooks that run in PowerShell not blocking when the hook's program exits with code 2, and on Windows <code>PreToolUse</code> and <code>PermissionRequest</code> hooks with <code>"shell": "powershell"</code> failing open when Git for Windows isn't installed</li>
<li>Fixed a mod's <code>turn.step</code> hook that names a model by alias, such as <code>haiku</code>, failing every request with a model error: the alias now resolves to its model</li>
<li>Fixed plugins and skills synced from claude.ai being removed, sometimes mid-session, after a disk read error</li>
<li>Fixed artifact publishes and updates being refused for some ordinary pages, such as pages with certain minified scripts or artifacts Claude could not read first</li>
<li>Fixed Claude asking for permission on each artifact update for the rest of a turn after the conversation was compacted in that turn</li>
<li>Fixed fine-grained tool streaming staying off on Amazon Bedrock when <code>ANTHROPIC_BEDROCK_BASE_URL</code> is set to the default <code>bedrock-runtime.&lt;region&gt;.amazonaws.com</code> endpoint</li>
<li>Fixed the "Waiting for API response" hint flickering behind gateways that send only keepalive pings: routes off Anthropic's backend now wait 45 seconds</li>
<li>Fixed Claude notifying unrelated GitHub users by writing role names and placeholders as mentions in PRs, issues and comments</li>
<li>Linux: Fixed sandbox write denies lifting when a background command outlived the session</li>
<li>Windows: Fixed PowerShell permission checks auto-approving some <code>Set-Location</code> or <code>cd</code> commands that target the current directory and carry extra arguments; these now prompt for approval</li>
<li>macOS: Fixed the "Install Command Line Developer Tools" dialog opening each time Claude Code starts on a Mac without Xcode or the Command Line Tools</li>
<li>Self-hosted runner: Fixed <code>--startup-timeout-min</code> stopping a session whose first prompt, such as <code>/code-review</code>, was still working in a subagent; a frozen process is still stopped</li>
<li>Improved the speed of many git commands Claude Code runs for itself on Windows; on every platform, errors from those commands now show in English even when git is set to another language</li>
<li>Improved the error when a hooks module is nested too deep to load: it now names the file instead of showing a bare stack-overflow message</li>
<li>Improved disk-full handling: a Bash command cut off by a full disk now says so and names the folder to free up, and starting on a full temp volume prints a clear message, not a raw ENOSPC error</li>
<li>Improved the /claude-api skill to offer API tracing alongside SDK tracing when asked to add OpenTelemetry</li>
<li>Improved the /claude-api skill to check the live docs before saying a feature is unsupported</li>
<li>Self-hosted runner: Improved sessions that move to a new runner: Claude now sees the tool call that was interrupted, marked as outcome unknown</li>
<li>Updated the bundled dataviz skill to accept APCA as a text-contrast measure (keeping WCAG 2 ratios where AA conformance is required), add an <code>apca(text, background)</code> function to its palette validator scripts, and say whether a label inside a colored chart fill should be white or near-black</li>
<li>Updated the /claude-api skill: service account keys and Workload Identity Federation tokens can now manage OpenTelemetry destinations</li>
<li>Changed <code>sed -i</code> to get the standard Bash prompt and run as written, not a simulated file-edit preview; like other Bash edits, it is no longer restored by <code>/rewind</code></li>
<li>Changed <code>claude ultrareview</code> to require workspace trust: it asks on a terminal, else refuses; scripts pass <code>--trust-workspace</code>, which takes no value (put a PR number or base branch before it), or set <code>CLAUDE_CODE_DISABLE_ULTRAREVIEW_TRUST_CHECK=1</code></li>
<li>Changed the dangerous <code>rm</code> and <code>rmdir</code> prompt in bypass permissions mode in the Desktop app and VS Code to deny the command at once with a rewrite hint, so unattended sessions keep going</li>
<li>Changed commands the settings exclude from the sandbox to ask before writing to its write-list paths while the sandbox is enabled but cannot run; the unsandboxed fallback is refused there</li>
<li>Changed worktree creation and reuse so git no longer fetches objects on demand, in ordinary clones and in partial clones with a Bash sandbox configured; such a partial clone fetches them first</li>
<li>Changed the <code>/claude-api</code> skill to build Managed Agents subagent teams on <code>multiagent_20261001</code> with dynamic workflows on by default, instead of <code>coordinator</code></li>
<li>[VSCode] Added a log warning that says what to do when dictation or the extension's own requests fail certificate verification, such as behind a TLS-inspecting proxy</li>
<li>[VSCode] Fixed the Claude panel staying blank after the editor cached an incomplete copy of its files; it now recovers by itself, or says what went wrong and how to fix it</li>
<li>[VSCode] Fixed Session history filling up with empty "Untitled" sessions each time you start a new session without sending a message</li>
<li>[VSCode] Fixed long slash-command messages such as <code>/goal</code> filling the chat panel; they now fold behind Show more like other prompts (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5595521927" data-permission-text="Title is private" data-url="https://github.com/anthropics/claude-code/issues/97469" data-hovercard-type="issue" data-hovercard-url="/anthropics/claude-code/issues/97469/hovercard" href="https://github.com/anthropics/claude-code/issues/97469">#97469</a>)</li>
<li>[VSCode] Fixed long messages not folding behind Show more after the chat panel is made narrower</li>
<li>[VSCode] Fixed Ctrl+J in the chat input always inserting a newline: it is now left to VS Code and the OS when "ctrl+j" is set to null in the Chat context of ~/.claude/keybindings.json</li>
<li>[VSCode] Fixed a mod's "From the … plugin" label above the prompt being drawn over the slash command and @-mention menus (<a class="issue-link js-issue-link" data-error-text="Failed to load title" data-id="5897869454" data-permission-text="Title is private" data-url="https://github.com/anthropics/claude-code/issues/102981" data-hovercard-type="issue" data-hovercard-url="/anthropics/claude-code/issues/102981/hovercard" href="https://github.com/anthropics/claude-code/issues/102981">#102981</a>)</li>
<li>[VSCode] Fixed an empty list item, paragraph or code block, and list items renumbered from 1, when pasting copied LaTeX math</li>
<li>[VSCode] Fixed the feedback error showing only an HTTP status when your organization does not accept feedback</li>
<li>[VSCode] Improved Edit and Write speed in the chat panel: the wait for new problems after each edit is now 0.75 seconds in most cases, down from 1 to 1.5 seconds</li>
<li>[Cloud sessions] Fixed the Add connector list in routine forms saying no connectors were available while they were still loading</li>
<li>[Cloud sessions] Fixed the cloud environment editor shuffling environment variables and adding backslashes to values that contain both kinds of quote</li>
<li>[Cloud sessions] Fixed the self-hosted environment details dialog in admin settings so its title, tabs and buttons stay in view while only the content scrolls</li>
<li>[Cloud sessions] Fixed the "read documentation" tool row in cloud sessions, which showed escaped JSON instead of a readable page</li>
<li>[Cloud sessions] Improved a cloud session's Changes pane, which now says when it lists only pushed commits or only Claude's edits</li>
<li>[Claude Tag] Fixed Claude in Slack posting a draft you approved for a channel into your DM by mistake; a post with no channel is now refused so it can go to the approved channel</li>
<li>[Claude Tag] Fixed Allow and Deny on Claude's approval cards in Slack doing nothing when the session had stopped; your answer now restarts the session</li>
<li>[Claude Tag] Fixed Claude ignoring untagged messages in a Slack channel after its workspace moved to a different Claude organization, including unshared channels on Enterprise Grid</li>
<li>[Claude Tag] Fixed Claude in a Slack channel posting a threaded reply before reading a newer message someone had just added to that thread</li>
<li>[Claude Tag] Fixed the Slack page in Claude Tag admin settings saying no workspaces were connected when the list failed to load; it now shows an error with a Retry button</li>
<li>[Code Review] Fixed a finished review showing no check on the pull request when earlier tries to create it failed; a final try now adds a completed check</li>
<li>[Code Review] Fixed a push queued behind a running review still starting a review after <code>@claude review stop</code>; its check now closes and says why</li>
</ul>
