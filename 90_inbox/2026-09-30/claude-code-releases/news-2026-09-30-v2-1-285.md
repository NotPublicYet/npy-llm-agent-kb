## Summary
<h2>What's changed</h2>
<ul>
<li>Added <code>CLAUDE_CODE_DISABLE_WEB_FETCH</code> environment variable to turn off the WebFetch tool</li>

<li>Fixed Claude Code refusing to start when the OS denies reading the managed settings file; it now warns and starts without that file's policies. Other read errors and unparseable files stop every session</li>
<li>Fixed cloud sessions that restarted after their conversation was compacted refusing the next update to an artifact the session had already read or published</li>
<li>Fixed <code>claude plugin disable</code> and <code>enable</code> with a full <code>name@marketplace</code> id changing a settings entry in another letter case instead of the installed plugin's own</li>
<li>Fixed files attached to a message sent over Remote Control being left out after a single failed download; a network error, timeout or server error is now retried up to twice</li>

<li>Fixed <code>claude mcp list</code> and <code>claude mcp get</code>, and the not-found error of <code>claude mcp remove</code>, <code>login</code> and <code>logout</code>, printing line breaks and terminal escape sequences from MCP server names and values</li>
