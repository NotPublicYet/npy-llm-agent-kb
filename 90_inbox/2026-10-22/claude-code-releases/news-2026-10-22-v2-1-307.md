## Summary
<h2>What's changed</h2>
<ul>
<li>Added <code>/claude-api api-version</code> to move Claude API code to API version <code>2026-10-21</code></li>
<li>Added the <code>claude_code.safety_event</code> OpenTelemetry event for each tool call a permission rule, auto mode, a safety check, a hook or the sandbox stopped, prompted or sent back</li>
<li>Fixed requests failing with a model-not-found error when <code>CLAUDE_CODE_DISABLE_1M_CONTEXT</code> is set and the model is an alias with the <code>[1m]</code> suffix, such as <code>opus[1m]</code></li>
<li>Fixed the <code>prompt-caching-scope</code> beta header being sent behind custom <code>ANTHROPIC_BASE_URL</code> gateways and on Foundry, where it has no effect</li>
<li>Fixed MCP servers showing "needs authentication" in <code>claude -p</code> on macOS while the login keychain was locked; they now say why, and the next run after an unlock connects without a new sign-in</li>
<li>Fixed MCP servers being reported as timed out, and staying failed in headless runs, when a macOS or Linux computer went to sleep while they were connecting</li>
<li>Fixed HTTP MCP tool calls being sent twice when the connection closed mid-call; only read-only or idempotent tools are now retried</li>
<li>Fixed a turn sometimes starting without an SDK MCP server's latest tools when a background task was running</li>
<li>Fixed some "Autocompact is thrashing" errors in turns that read many PDF pages, images or other large tool results</li>
<li>Fixed <code>/autocompact</code> in cloud sessions going back to the default window after the session restarted</li>
<li>Fixed a conversation cleared with <code>/clear</code> sometimes coming back when a cloud or self-hosted runner session restarted</li>
<li>Fixed <code>CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS</code> being ignored in Claude apps gateway sessions</li>
<li>Fixed telemetry from Claude Desktop sessions behind a Claude apps gateway being rejected when <code>OTEL_EXPORTER_OTLP_HEADERS</code> is set</li>
<li>Fixed <code>/permissions</code> &gt; Recently denied not showing the denied shell command, and auto mode's local classifier ignoring an approval from there when it checks a retried command; approving a row now names the command, not its description</li>
<li>Fixed <code>/help</code> and the <code>/</code> command menu showing long model-facing descriptions for bundled skills such as <code>/claude-api</code> instead of their short descriptions</li>
<li>Fixed subagent transcripts recording placeholder token usage and an empty stop reason for streamed responses</li>
<li>Fixed model switches through the Agent SDK's <code>setModel()</code>, and apps built on it, being refused when the API took more than 5 seconds to confirm the model; Claude Code now waits up to 15 seconds</li>
<li>Fixed a background command stopped through a connected app (such as the desktop app archiving an idle session) being reported to Claude as stopped by the user; the notice now names its output file</li>
<li>Fixed WebFetch in Cowork cloud sessions reporting a tool error when a site answered with a 4xx status or a robots.txt refusal; it is now a normal result, as in local sessions</li>
<li>Fixed write tools on a directly configured GitHub MCP server showing a form that closed without creating anything in the desktop app's Code tab</li>
<li>Fixed Artifact tool reads failing with a connection reset when the server had closed a reused connection</li>
<li>Self-hosted runner: Fixed sessions with <code>--use-anthropic-git-proxy</code> committing a <code>.claude/settings.local.json</code> left in the clone by an earlier session</li>
<li>Self-hosted runner: Fixed archiving or requeueing a session, or stopping the runner, during its checkout hook leaving the hook's processes running and the runner's slot held</li>
<li>Improved recovery from unparseable tool calls: Claude Code now retries the call up to twice before ending the turn with an error</li>
<li>Improved fork subagents launched together: each is now told which launch is its own, so forks are much less likely to try to start each other's work</li>
<li>Improved browser sign-in: the success page now appears as soon as sign-in completes, without waiting for your account profile to load</li>
<li>Improved web search errors in cloud and self-hosted runner sessions: a search refused with a 403 that gives a reason now shows that reason instead of a generic "Authentication error"</li>
<li>Improved the time to the first reply in cloud sessions when one of the desktop app's MCP servers can't connect</li>
<li>Improved Remote Control connect time for sessions whose transcript contains large pasted images or PDF reads</li>
<li>Changed the notice Claude gets when the WebSearch budget is used up to also tell it not to query search engines in a browser or through computer use</li>
<li>Changed the <code>axScreenReader</code> setting and <code>CLAUDE_AX_SCREEN_READER</code> in a settings <code>env</code> block to apply only from user, managed or <code>--settings</code> settings (since 2.1.305)</li>
<li>Self-hosted runner: Changed checkout hooks to be stopped after 30 minutes by default, failing the session's setup; if yours needs longer, raise <code>--checkout-hook-timeout-min</code> or set it to <code>0</code></li>
<li>Self-hosted runner: Changed the certificate file built for Anthropic-managed git to filter its trusted certificates as the CLI does; a <code>[runner:warn]</code> line gives the number left out</li>
<li>[VSCode] Added a notice on the microphone button when voice dictation stops by itself (15 seconds without recognized speech, or the 2-minute limit), saying why and that the text so far is kept</li>
<li>[VSCode] Fixed a long prompt expanded with Show more covering the whole chat panel: a pinned prompt is now capped at 40% of the panel and scrolls</li>
<li>[VSCode] Fixed part of a list item or table cell with LaTeX math pasting as a new list or table in rich text editors</li>
<li>[VSCode] Fixed dictation failing behind a TLS-inspecting proxy when <code>NODE_EXTRA_CA_CERTS</code> is set only in <code>~/.claude/settings.json</code>; it now also follows <code>CLAUDE_CODE_CERT_STORE</code></li>
<li>[VSCode] Changed the "still open somewhere else" notice to also cover a Claude process left over from an extension restart, which usually ends on its own within about 10 minutes</li>
<li>[VSCode] Changed voice dictation to filter its trusted certificates as the CLI does</li>
<li>[VSCode] Changed the extension's own requests to filter their trusted certificates as the CLI does, and to trust the <code>NODE_EXTRA_CA_CERTS</code> file named in the environment or in user settings</li>
<li>[Cloud sessions] Fixed the repository picker saying "No repositories match" while a search was still running; it now shows "Searching…" until the results arrive</li>
<li>[Cloud sessions] Fixed the "Waiting for a runner" status on self-hosted environments being cut off; with on-demand runners it now counts up from your last message and shows failed attempts</li>
<li>[Code Review] Added <code>@claude review stop</code> (also <code>off</code> and <code>pause</code>) to Code Review, ending an <code>@claude review always</code> subscription on a pull request without starting a new review</li>
</ul>
