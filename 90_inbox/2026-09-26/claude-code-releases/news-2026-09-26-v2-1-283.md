## Summary
<h2>What's changed</h2>
<ul>
<li>Added <code>x-claude-code-prompt-id</code> to the gateway hint headers so LLM gateways can group the requests that serve one user prompt; opt in with <code>CLAUDE_CODE_GATEWAY_HINT_HEADERS=1</code></li>
<li>Added <code>availableModelsMatch</code> managed setting: with <code>"exact"</code>, an <code>availableModels</code> entry allows only the model version it names, so new releases stay blocked until listed</li>
<li>Added <code>deniedModels</code> managed setting to block specific models, even when <code>availableModels</code> allows them</li>
<li>Added MCP tool, WebFetch and WebSearch outputs to the <code>tool.output</code> OpenTelemetry span event when <code>OTEL_LOG_TOOL_CONTENT=1</code></li>
<li>Added <code>/doctor prompt-audit</code> (also <code>/checkup prompt-audit</code>) to audit your CLAUDE.md files, skills, agents and commands for prompting patterns written for older models</li>
<li>Added click-to-expand for truncated messages from your other sessions in fullscreen mode</li>
<li>Added <code>path</code> to <code>--plugin-dir</code> load-failure entries in the stream-json <code>system/init</code> <code>plugin_errors</code>, naming the directory that did not load</li>
<li>Added an opt-in <code>load_test_mode</code> block to the Claude apps gateway config: requests are built and signed but not sent upstream, and clients get a canned reply, so a deployment can be load tested</li>
<li>Added a <code>mantle</code> upstream provider to the Claude apps gateway for Amazon Bedrock's Mantle endpoint</li>
<li>Fixed SDK sessions losing a deferred tool call or finished tool result when a turn ended early, a held approval prompt after a worker restart, and a non-streaming fallback's <code>result.usage</code></li>
<li>Fixed MCP progress notifications being discarded once a long-running tool call moved to the background; the background task now shows the latest progress</li>
<li>Fixed stdio MCP servers being left running when the session ended while they were still starting</li>
<li>Fixed a brief HTTP 404 from a stateless remote MCP server (for example a proxy mid-redeploy) leaving that server unusable for the rest of the session while still shown as connected</li>
<li>Fixed MCP sign-in for a server with no valid URL failing with an opaque SDK error; <code>/mcp</code> no longer offers Authenticate for such servers</li>
<li>Fixed the weekly Fable limit not appearing in <code>/usage</code> and the VS Code usage meters when telemetry is disabled</li>
<li>Fixed <code>/model</code> accepting Sonnet 4.6 or Sonnet 5 with <code>[1m]</code> when the id carried a date or <code>-v1:0</code> suffix, in the cases where the plain id was refused</li>
<li>Fixed <code>/model</code> picker showing a hardcoded Haiku version and price when <code>ANTHROPIC_DEFAULT_HAIKU_MODEL</code> pins a different model</li>
<li>Fixed dynamic workflows started during a model fallback running every agent on the fallback model instead of retrying the configured model</li>
<li>Fixed <code>DISABLE_PROMPT_CACHING_HAIKU</code> having no effect when Haiku is the session's main model</li>
<li>Fixed <code>claude plugin validate</code> saying Claude Code accepts a plugin or marketplace name it cannot install; such names in <code>marketplace.json</code> now fail validation</li>
<li>Fixed <code>claude plugin validate</code> passing plugins whose <code>outputStyles</code>, <code>themes</code>, <code>monitors</code>, or <code>lspServers</code> paths are missing or point outside the plugin directory</li>
<li>Fixed <code>claude plugin details</code> showing 0 MCP servers for plugins that declare their servers in <code>plugin.json</code></li>
<li>Fixed <code>claude plugin marketplace remove</code> not saying which installed plugins it uninstalled with the marketplace; it now lists them</li>
<li>Fixed <code>claude plugin uninstall</code> removing the other of two installed plugins whose ids differ only in case, with its options and secrets, when the one named had no <code>enabledPlugins</code> entry at that scope</li>
<li>Fixed plugins that declare no version being silently restored at their source's newest commit, not the installed one, when their cached files were missing</li>
<li>Fixed user-installed plugins and marketplaces failing to load with "cache-miss" after the home or config directory was moved, for example in bind-mounted devcontainers</li>
<li>Fixed <code>installed_plugins.json</code> showing no plugins when it holds a record under an invalid plugin id; such a file loads again</li>
<li>Fixed <code>installed_plugins.json</code> being rewritten, losing records, when it holds a record this version cannot read; <code>claude plugin</code> commands now name the record and say how to recover</li>
<li>Fixed permission dialogs in screen-reader mode reading quoted commands and paths as if they were the dialog's own text</li>
<li>Fixed <code>/context</code> not counting MCP server instructions: they now appear as their own row and count toward the total</li>
<li>Fixed markdown links in the Warp terminal rendering as plain text instead of clickable hyperlinks</li>
<li>Fixed <code>claude mcp add</code>, <code>add-json</code>, and <code>remove</code> reporting success when the user or local config file could not be written, for example inside a sandbox</li>
<li>Fixed the first words of a reply in a cloud session sometimes appearing late instead of streaming as Claude writes them</li>
<li>Fixed Claude's built-in keybindings guide saying chords time out after 1 second instead of 3, and calling <code>cmd</code> an alias of <code>meta</code>, which could produce <code>cmd+</code> shortcuts most terminals never send</li>
<li>Fixed <code>keybindings.json</code> silently accepting a misspelled modifier such as <code>ctl+k</code>; it now warns in the debug log and suggests the fix</li>
<li>Fixed footer hints still saying "Enter to view" after <code>footer:openSelected</code> was rebound or unbound in <code>keybindings.json</code></li>
<li>Fixed keys typed quickly together (type-ahead, key repeat, bursts over ssh or tmux) sometimes being handled against stale state</li>
<li>Fixed worktree checkouts failing certificate verification (for example on Git LFS downloads) when the CA certificate is passed to git as <code>GIT_CONFIG_COUNT</code> environment pairs</li>
<li>Fixed sandboxed <code>git</code> asking credential helpers to store the sandbox proxy's login, which printed "failed to store"</li>
<li>Fixed managed <code>sandbox</code> settings being ignored entirely when one nested value was invalid; the invalid value now fails closed and the rest of the block still applies</li>
<li>Fixed Claude's edits to its own auto-memory notes being blocked as sensitive-file writes when Claude Code was started in a subdirectory of a git repository</li>
<li>Fixed Remote Control being unavailable on paid plans when telemetry is turned off with <code>DISABLE_TELEMETRY</code> or <code>DO_NOT_TRACK</code></li>
<li>Fixed the <code>/remote-control</code> menu cutting its QR-code hint mid-word in narrow terminals</li>
<li>Fixed vim mode <code>.</code> dropping a Shift+Enter newline, leaving the cursor inside an accented letter, and repeating an older change after <code>3J</code> or Visual-mode <code>J</code> on the last line</li>
<li>Fixed vim mode cursor placement: recalling a prompt over 10,000 characters in normal mode no longer leaves the cursor past the end, and <code>V</code> then <code>p</code> now lands on the first non-blank</li>
<li>Fixed vim mode <code>J</code> joining lines with different spacing than Vim (such as a space before <code>)</code> or after a tab), and <code>3J</code> or Visual-mode <code>J</code> on the last line not moving the cursor as Vim does</li>
<li>Windows: Fixed the PowerShell tool letting <code>cmd /c rd</code>, <code>rmdir</code>, <code>del</code> or <code>erase</code> delete drive roots, the home folder and other folders that <code>Remove-Item</code> refuses</li>
<li>Improved the <code>/mcp</code> tool list: it shows more tools at once, scrolls with the page keys and mouse, and marks tools your organization blocked with a warning icon</li>
<li>Improved MCP tool results: images returned by MCP tools are now also saved to a file, so Bash, Read and other tools can open them</li>
<li>Improved <code>/tasks</code>: rows show a status icon, the name and whole facts, the title and key hints stay on screen with many tasks, and the list gains paging keys, the mouse wheel and clicks</li>

<li>Improved lists beside a search box, such as <code>/skills</code> and <code>/artifacts</code>, to draw their pointer dim while the search box has the keys, so only one pointer is highlighted</li>
<li>Improved the compaction spinner: its timer now starts when compaction begins and it counts the summary's tokens as they stream, replacing the percentage bar</li>
<li>Improved the browser page shown after signing in to an MCP server: centered layout, dark mode, and new artwork</li>
<li>Improved the Skill tool's reply when a skill belongs to a plugin that failed to load, so Claude tells you the plugin could not be loaded instead of calling the skill uninstalled</li>
<li>Improved <code>prompt-audit</code> on Claude Code configuration: stale paths, stale commands and contradicting instruction files now lead the report, and thinking keywords that Claude Code documents are kept</li>
<li>Improved recovery from an <code>installed_plugins.json</code> that cannot be read at all: its contents are kept in a file beside it before it is rebuilt, and <code>claude plugin list</code> names that file</li>
