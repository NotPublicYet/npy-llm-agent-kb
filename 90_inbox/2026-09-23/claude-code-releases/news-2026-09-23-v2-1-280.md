<ul>
<li>Added Claude Opus 5.5 (<code>claude-opus-5-5</code>), now the default Opus model — 1M context, $4/$20 per Mtok with $0.20/Mtok cache reads</li>

<li>Fixed subagent hand-back messages showing an internal provenance preamble when expanded outside verbose mode</li>

<li>Fixed Home and End doing nothing in the <code>/config</code> settings list and in selection lists such as <code>/model</code>, <code>/memory</code> and permission prompts</li>
<li>Fixed PgUp/PgDn in the <code>/skills</code> menu wrapping past the first or last skill instead of stopping there</li>
<li>Fixed Tab silently changing the selected setting's value in the <code>/config</code> list; it now does nothing there</li>

<li>Fixed a session failing on every turn and <code>/compact</code> when its saved history held a malformed notice about MCP tools that could not be loaded</li>
<li>Fixed a crash when resuming a session whose saved transcript holds a malformed system message or a memory-saved notice without its file list</li>
