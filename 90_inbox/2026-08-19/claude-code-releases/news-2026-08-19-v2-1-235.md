## Summary
<h2>What's changed</h2>
<ul>
<li>Added an optional <code>spellcheck</code> setting that underlines misspelled words in the prompt input as you type, using your installed <code>aspell</code>, <code>hunspell</code>, or <code>ispell</code></li>
<li>Fixed whole-prompt-cache invalidation when a language server disconnected or reconnected mid-session</li>
<li>Fixed nested markdown list items misaligning at depth 3+ and added a hanging indent to wrapped list items in the terminal UI</li>
<li>Fixed prompt input highlights (slash commands, keywords, mentions) appearing shifted by one or more characters in some multi-line prompts</li>
<li>Fixed Shift+Tab inside the permission prompt's comment field approving the edit and granting session-wide edit permission instead of closing the field</li>
<li>Fixed the Agent tool advertising a general-purpose default in sessions where that agent is unavailable: an omitted <code>subagent_type</code> there now gets a clear error listing the available agents</li>
<li>Fixed notebook cell delete/replace approval dialogs silently omitting the existing cell content when the notebook or cell could not be read; the dialog now says why</li>
<li>Fixed slash commands run while Claude is responding showing HTML entities instead of the actual characters</li>
<li>Fixed the prompt footer not showing the "Update installed" restart notice after a background auto-update</li>
<li>Fixed the expanded task list (<code>ctrl+t</code>) always starting collapsed when resuming or relaunching into a session that still has open tasks</li>
<li>Improved memory and CPU usage while cloud sessions such as <code>/ultrareview</code> or <code>/autofix-pr</code> run in the background — their event streams are no longer re-scanned and re-rendered on every update</li>
<li>Improved permission dialogs: display text and "don't ask again" options now always match what a grant would cover, and "don't ask again" is withheld when contents cannot be fully displayed</li>
<li>Improved the embedded <code>grep</code> in native macOS/Linux builds: pathological patterns now fail fast instead of exhausting memory, and <code>-m N</code> with <code>-A/-C</code> prints correct context</li>
<li>Improved the context-limit error to say when auto-compact is off and point to <code>/config</code> to re-enable it</li>
<li>Vim mode: NORMAL mode and cursor position are now preserved when toggling the detailed transcript (ctrl+o) or closing a panel</li>
<li>Dialogs: arrow keys and Enter pressed in quick succession now select the option you navigated to instead of the previously highlighted one</li>
<li><code>SendMessage</code> now refuses messages too large for cross-session delivery up front instead of silently dropping them</li>
<li>Remote Control: <code>claude rc</code> now applies the same enterprise-gateway availability check as interactive startup</li>
<li>[VSCode] Fixed focus jumping between open Claude tabs on its own when a window with several Claude panels is restored or reloaded</li>
</ul>
