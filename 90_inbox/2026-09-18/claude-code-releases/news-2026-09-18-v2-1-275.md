## Summary
<h2>What's changed</h2>
<ul>
<li>Added the signed-in account to Claude apps gateway sign-in: when the gateway names it, you confirm it before the credential is saved, and <code>/status</code> shows it</li>
<li>Added a send-now key (ctrl+enter, or ctrl+x ctrl+s) that interrupts the current turn and sends all queued messages at once; sent and queued messages show in gray until the model receives them</li>
<li>Added a startup warning when a configured <code>otelHeadersHelper</code> fails, so sessions that silently export no telemetry are noticed</li>
<li>Added syncing of the skills and plugins enabled on your claude.ai account to terminal sessions signed in with it; opt out with <code>syncClaudeAiSkills: false</code> or <code>syncClaudeAiPlugins: false</code></li>
<li>Added <code>/plugin install &lt;plugin&gt; --marketplace &lt;source&gt;</code>, which offers to add the marketplace before installing the plugin</li>
<li>Fixed a restored memory file's age note changing between requests after a compaction or resume, which caused prompt cache misses</li>
<li>Fixed <code>--forward-subagent-text</code> stream-json and SDK output dropping the messages of subagents spawned by a <code>context: fork</code> skill, and of forked skills invoked by a subagent or another forked skill</li>
<li>Fixed @-mention file suggestions being buried below MCP resources when using a custom <code>fileSuggestion</code> command or typing <code>@.</code>/<code>@./</code></li>
<li>Fixed fullscreen mode placing background-task completion notices beneath a long turn's collapsed tool row instead of where they arrived; each notice now closes the open row</li>
<li>Fixed <code>claude plugin marketplace update</code> deleting a GitHub marketplace's local copy when the fetch failed and the marketplace was named after its repository</li>
<li>Fixed plugin and marketplace messages, logs and <code>claude plugin marketplace list</code> showing a password or token stored in a git, ssh or marketplace URL</li>
<li>Fixed a resumed cloud session leaving an unanswered question open in the transcript after a queued message superseded it</li>
<li>Fixed vim mode placing the cursor one character right after a dot-repeated "!" or a fast-typed "i!" switched a non-empty prompt into shell mode</li>
<li>Fixed fullscreen mode freezing or blanking for several seconds when scrolling up past a large file diff</li>
<li>Fixed a stray <code>&lt;/ccmemory&gt;</code>-style closing tag occasionally appearing in responses</li>
<li>Fixed plugin messages, logs and the VS Code plugin dialog showing the wrong server for some git addresses</li>
<li>Fixed a terminal <code>API Error: 400</code> on every turn for users behind a network gateway that rewrites API error responses when a beta request header is rejected</li>
<li>Fixed sandboxed Bash commands on Linux reporting exit code 0 for failed commands when the shell is zsh</li>
<li>Fixed the Read tool hanging instead of reporting an error when part of a large file could not be decoded under memory pressure</li>
<li>Fixed <code>--resume</code>, the resume picker preview, resumed background agents and the transcript view failing on a session whose saved history contains a malformed task-reminder or @-file attachment entry</li>
<li>Fixed a crash when resuming a conversation whose transcript contains a malformed message entry, and a fullscreen crash when such a conversation received new messages while scrolled up</li>
<li>Fixed sessions failing to resume or start when their saved transcript contains a malformed message content block</li>
<li>Fixed Grep, Glob and @-file suggestions hanging or running out of memory on searches over the 20MB output cap, and system ripgrep reporting "no matches" instead of an error after a flood of warnings</li>
<li>Fixed <code>/rewind</code> in a forked or background session restoring a zero-filled or truncated file when the session's file-history backups could not be fully copied</li>
<li>Fixed fullscreen sessions sometimes exiting with "Claude Code exited after an unrecoverable interface error" when typing fast or holding a key with the slash-command dropdown open</li>
<li>Fixed background sessions crashing and restarting their worker when a command fed through stdin ran on a machine that had run out of file descriptors</li>
<li>Fixed a crash at launch when <code>~/.claude.json</code> holds a malformed <code>mcpNeedsAuthNoticed</code> value</li>
<li>Fixed <code>--resume</code> and <code>--continue</code> dropping a conversation's earlier thinking when a built-in tool it started with has since been switched off by a server-side flag</li>
<li>Fixed text selected with the mouse in the fullscreen <code>claude --resume</code> session picker never reaching the clipboard</li>
<li>Fixed plugin reload previews replacing a running session's extracted plugin files when the plugin was loaded from a <code>--plugin-dir</code> or <code>--plugin-url</code> archive</li>
<li>Fixed self-hosted runners with <code>--drain-wait-sec</code> losing the final result of a turn that finished during a SIGTERM drain; the runner now waits briefly for the turn to be reported</li>
<li>Fixed <code>SubagentStop</code> hooks with a specific <code>matcher</code> firing for every stopping subagent whose agent type was empty</li>
<li>Fixed sandboxed Bash commands being unable to write to project directories named <code>hooks/</code> or <code>config/</code></li>
<li>Fixed Artifact updates failing with "File not found" after a session resumes on another machine or its scratchpad is cleared: the page's last published version is restored</li>
<li>Fixed <code>/update-config</code> writing <code>Write(path)</code> permission rules, which file permission checks don't match, instead of <code>Edit(path)</code> rules</li>
<li>Fixed four dead documentation URLs (Pricing, Computer Use, Skills, CLI) in the bundled claude-api skill's live-sources table</li>
<li>Improved prompt caching for a <code>--system-prompt</code> that contains a <code>__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__</code> line: the text above it is now cached globally, as the SDK's array form already is</li>
<li>Improved the <code>/desktop</code> error when Claude Desktop does not open: it now says why and what to do next</li>
<li>Improved the Artifact tool's publish and read results: they now say who can open the page and what the owner's Share menu offers</li>
<li>Improved artifact publish results: they name the tab icon sent, warn when the page contains a NUL byte, and retry a flaky fetch of the newer page to merge after a stale publish</li>
<li>Improved pasted and attached images: they are now saved where Claude can open them as files without a permission prompt, including in Desktop and VS Code</li>
<li>Improved the Artifact tool's guidance so Claude updates a shared artifact in place when you were given edit access to it, instead of publishing a separate copy</li>
<li>Improved plan-usage reads: editor windows and non-interactive sessions on one machine now share a read made in the last minute instead of each calling the usage endpoint</li>
<li>Improved the <code>ListPlugins</code> tool description so Claude knows it lists plugins enabled on your claude.ai account, not plugins installed locally with <code>/plugin</code></li>
<li>Improved responsiveness when the terminal is slow or paused: output no longer falls further behind while the terminal catches up</li>
<li>Improved Write and Edit results for files in the synced account-skills folder: they now say the change is not saved to your account and how to save it</li>
<li>Updated <code>/logout</code> for Claude apps gateway sign-ins to also end the session on gateways that advertise token revocation</li>
<li>Changed hosted sessions to keep an unanswered permission prompt up after a container restart, instead of asking again</li>
<li>Changed the Artifact tool to ask for a one-word tab icon on a first publish instead of an emoji favicon</li>
<li>Changed Claude in Chrome in auto mode to skip the extension's per-site check for classifier-approved calls, as bypass mode does, fixing <code>browser_batch</code> "Permission denied" after a redirect</li>
<li>Changed plugins installed from an npm source to be fetched with <code>npm pack --ignore-scripts</code> and integrity-verified, so a package's install scripts no longer run</li>
<li>Changed scheduled and Run now routine runs to save data to, and republish the page of, an artifact you can edit without asking; public artifacts, first publishes and deletes still ask</li>
<li>Removed the startup notice that told you a one-off scheduled routine had run since your last session</li>
<li>[VSCode] Added viewing, editing and deleting a saved memory inside the Memory dialog</li>
<li>[VSCode] Added sending an attached image without typing any text</li>
<li>[VSCode] Added a Retry link to the MCP servers dialog when the server list fails to load</li>
<li>[VSCode] Added accept and reject buttons under each change in the proposed-change diff tab, so an edit can be reviewed change by change</li>
<li>[VSCode] Fixed the transcript creeping toward the bottom in small steps while a permission card waits and content keeps arriving</li>
<li>[VSCode] Fixed rewound and forked conversations not keeping the permission mode you had picked for the original conversation</li>
<li>[VSCode] Fixed an empty <code>CLAUDE_CONFIG_DIR</code> entry in the <code>environmentVariables</code> setting making Claude Code keep its files in the workspace</li>
<li>[VSCode] Fixed plugin install links opening the Manage plugins dialog for plugin names and marketplace addresses that can't be used in a link</li>
<li>[VSCode] Fixed Remote Control staying shown as connected after a turn-off that Claude Code reported as failed; it now shows as off</li>
<li>[VSCode] Fixed the scroll to the bottom on send stopping short of the reply when the reply starts arriving during the scroll</li>
<li>[VSCode] Fixed the agent map showing agents a crash left unfinished as stopped instead of failed once the session is reopened</li>
<li>[VSCode] Fixed the "Continuing the step" notice not appearing, and the continue limit resetting, after a reload that follows a crash with background tasks still running</li>
<li>[VSCode] Fixed the session list showing when a session was last reopened, such as after a window reload, instead of when its last message was sent</li>
<li>[VSCode] Fixed "Fork conversation from here" failing on the message right after one sent while Claude was working</li>
<li>[VSCode] Fixed the prompt cache clock showing too few minutes after reopening a session with a message sent while Claude was working</li>
<li>[VSCode] Fixed a background agent that finished while Claude was running a tool losing its completion notice, and its result on the agent map, after a window reload</li>
<li>[VSCode] Fixed a rare case where text selected in a git-ignored file could be sent to Claude after the extension was unresponsive for several seconds</li>
<li>[VSCode] Fixed renaming a running session reverting to the generated name (regression in 2.1.269)</li>
<li>[VSCode] Fixed some claude.ai/code sessions opening in VS Code as an empty conversation with no messages</li>
<li>[VSCode] Fixed slash commands typed while Claude is responding being sent to the model as text instead of running once the response finishes</li>
<li>[VSCode] Fixed unreadable code in the plan preview and the Hooks and Permission rules dialogs with the High Contrast Light theme</li>
<li>[VSCode] Fixed <code>/remote-control</code> being ignored while Remote Control is still connecting: running it again now turns Remote Control off immediately</li>
<li>[VSCode] Fixed the conversation pulling you back to the bottom while a reply streams after you scroll up, and added a <code>claudeCode.scrollToBottomOnSend</code> setting to turn off the jump on send</li>
<li>[VSCode] Fixed the Manage plugins dialog showing a password or token that was typed into a marketplace URL</li>
<li>[VSCode] Improved the agent map: the pill counts running agents and turns red after a failure, the main agent stays in view while the map scrolls, and agents sort by state then end time</li>
<li>[VSCode] Changed New session in a Claude editor tab to open in the sidebar when Preferred Location is set to Sidebar, instead of always opening another tab</li>
<li>[VSCode] Changed a message sent while Claude is working to wait at the bottom of the conversation until Claude starts on it</li>
<li>[Claude Code on the web] Added a "New routine" button to the page shown when a routine link no longer resolves, next to the link back to your routines list</li>
<li>[Claude Code on the web] Fixed routine "paused" and "on hold" notifications being cut off mid-sentence; the paused-subscription notice now says to turn the routine back on yourself</li>
<li>[Claude Code on the web] Fixed cloud environments with a very long allowed-domains list saving fine and then failing every session start; saving now fails up front and says how much to trim</li>
<li>[Claude Code on the web] Fixed Claude's guidance when a cloud session on a personal account is denied GitHub access: it now links to claude.ai/connect-github instead of an admin settings page</li>
<li>[Claude Code on the web] Improved what Claude tells you when asked to edit, delete or run a routine it didn't create: it now links to the routine's page so you can do it yourself</li>
<li>[Claude Tag] Added attach conditions for access bundles in Claude Tag settings: an Owner can let a bundle also apply in channels with guests or Slack Connect channels, not just member-only</li>
<li>[Claude Tag] Added Amazon CloudWatch, CloudWatch Logs, Amazon SNS, Google Cloud Monitoring and Cloud Logging presets to an access bundle's Credentials tab in Claude Tag admin settings</li>
<li>[Claude Tag] Added Datadog presets for the US3, AP1, AP2 and US1-FED sites; new Datadog connections are now limited to Datadog's read and query API routes</li>
<li>[Claude Tag] Fixed S3 uploads from recent AWS CLI and SDK versions failing with a 502 error when sent through an AWS connection</li>
<li>[Claude Tag] Fixed Claude treating a channel as inactive, and skipping untagged messages there, while it was still posting in that channel from a routine or a thread</li>
<li>[Claude Tag] Fixed a thread's "Claude [task]" display name reverting to plain "Claude" after the session behind that thread was refreshed or restarted</li>
<li>[Claude Tag] Fixed the model you switched to in a Slack thread silently reverting to the channel's default after that thread's session was restarted or refreshed</li>
<li>[Claude Tag] Fixed Claude sometimes replying twice when another app or bot @mentioned it in a top-level channel message</li>
<li>[Claude Tag] Improved Claude's notices in Enterprise Grid channels shared across workspaces: they now say when no workspace is set up yet, or why only organization defaults apply</li>
<li>[Code Review] Fixed reviews occasionally dropping part of their analysis when one of the reviewing agents returned its findings in an unexpected format</li>
